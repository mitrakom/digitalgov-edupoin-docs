    Pengenalan Singkat

    Apa itu Modul Ajar?

    Modul Ajar (juga disebut RPP - Rencana Pelaksanaan Pembelajaran) adalah dokumen perencanaan pembelajaran yang dibuat oleh Guru sebelum mengajar. Fitur ini memudahkan Guru untuk:

    • 📤 Mengunggah file RPP secara teratur
    • 📊 Melacak status evaluasi RPP mereka
    • 📝 Menerima feedback dari Tim Penilai atau Kepala Sekolah

    Apa itu Monitoring Kelas?

    Monitoring Kelas adalah catatan observasi pengajaran Guru di dalam kelas yang dilakukan oleh Kepala Sekolah atau Tim Penilai. Penilaian ini membantu:

    • 👁️ Mengamati kualitas proses belajar mengajar
    • 📈 Memberikan data untuk pengembangan kinerja guru
    • 💡 Memberikan feedback konstruktif

    Akses Modul Ajar

    Cara Login

    1. Buka aplikasi EduPoin di browser/smartphone
    2. Klik "Login"
    3. Masukkan Username dan Password Anda
    4. Klik "Masuk"

    Menavigasi ke Modul Ajar

    Setelah login, Anda akan melihat dashboard aplikasi:

    1. Di menu sebelah kiri, cari "Modul Ajar" atau "Pembelajaran"
    2. Klik untuk membuka halaman Modul Ajar
    3. Atau gunakan URL: https://edupoin.sekolah.id/app/modul-ajar

    Panduan Guru: Upload RPP

    Langkah 1: Akses Halaman Upload

    1. Login ke aplikasi sebagai Guru atau Guru Wali
    2. Buka menu "Modul Ajar" di sidebar
    3. Klik tombol "Upload RPP Baru" atau "+ Tambah"

    Langkah 2: Isi Formulir Upload

    Field Cara Isi
    Mata Pelajaran Pilih dari dropdown (sistem hanya menampilkan mapel yang Anda ajarkan)
    Judul RPP Ketik judul/nama RPP, contoh: "Perpangkatan Bilangan Bulat - Kelas VII"
    Deskripsi (Opsional) Tambahkan deskripsi singkat atau catatan
    Pilih File Klik untuk memilih file dari komputer (format: PDF, DOC, atau DOCX; maksimal 5 MB)

    Langkah 3: Simpan

    1. Setelah mengisi semua field wajib, klik tombol "Simpan" atau "Upload"
    2. Tunggu beberapa detik hingga file selesai diupload
    3. Anda akan melihat pesan "Berhasil! RPP telah diupload"
    4. RPP Anda sekarang masuk ke antrian evaluasi dengan status "Menunggu Evaluasi"

    Status RPP Anda

    Setelah upload, pantau status RPP di daftar:

    Status Arti
    Menunggu Evaluasi RPP sedang menunggu untuk dinilai oleh Tim Penilai
    Sedang Dievaluasi Tim Penilai sedang meninjau RPP Anda
    Dinilai Evaluasi selesai dan ada nilai/feedback dari Penilai
    Revisi Diminta Tim Penilai meminta Anda merevisi RPP tertentu

    Tips Guru

    ✅ Upload secara teratur — Sistem akan meminta setidaknya 1 RPP per mapel per semester
    ✅ Gunakan nama file deskriptif — "RPP_Matematika_Bab3_Desember2025" lebih baik daripada "RPP_final"
    ✅ Cek feedback — Buka notifikasi untuk melihat kapan ada feedback dari Tim Penilai
    ✅ Revisi dengan cepat — Jika diminta revisi, upload versi yang diperbaiki dalam 7 hari kerja

    Panduan Wali Kelas: Monitoring RPP

    Peran Wali Kelas

    Sebagai Wali Kelas, Anda dapat: - 👁️ Melihat daftar semua guru di kelas Anda - 📊 Memantau status RPP setiap guru - 📝 Memberikan catatan/saran kepada guru (opsional)

    Langkah: Lihat Status RPP Guru

    1. Login sebagai Wali Kelas
    2. Buka menu "Modul Ajar"
    3. Pilih "Dashboard Guru" atau "Monitoring RPP"
    4. Anda akan melihat tabel berisi:
    5. Nama Guru
    6. Mata Pelajaran
    7. Jumlah RPP yang diupload
    8. Status terbaru setiap RPP
    9. Tanggal upload terakhir

    Memberikan Catatan (Opsional)

    Jika ingin memberikan saran kepada guru:

    1. Klik "Lihat Detail" pada salah satu guru
    2. Di bagian komentar, ketik catatan Anda
    3. Klik "Kirim Catatan"
    4. Guru akan menerima notifikasi

    Panduan Tim Penilai: Evaluasi RPP

    Peran Tim Penilai

    Anda ditunjuk sebagai Tim Penilai untuk: - ✅ Meninjau dan mengevaluasi setiap RPP yang diupload - 📊 Memberikan nilai/skor kualitas RPP - 📝 Memberikan feedback atau saran perbaikan

    Langkah 1: Akses Antrian Evaluasi

    1. Login sebagai Tim Penilai
    2. Buka menu "Evaluasi RPP" atau "Modul Ajar"
    3. Anda akan melihat daftar RPP yang "Menunggu Evaluasi"

    Langkah 2: Pilih RPP untuk Dievaluasi

    1. Klik RPP yang ingin dievaluasi
    2. Halaman detail RPP akan terbuka dengan:
    3. Nama Guru
    4. Mata Pelajaran
    5. Judul & Deskripsi RPP
    6. Link download file RPP
    7. Form Evaluasi

    Langkah 3: Download & Review File RPP

    1. Klik tombol "Download" untuk menyimpan file RPP ke komputer
    2. Buka file dengan software yang sesuai (MS Word, Adobe PDF Reader, dll)
    3. Baca dan review isi RPP

    Langkah 4: Isi Form Evaluasi

    Setelah review, kembali ke halaman detail RPP dan isi form evaluasi:

    Field Cara Isi
    Nilai/Skor Masukkan nilai 1-100 berdasarkan kualitas RPP
    Status Pilih: "Disetujui" atau "Revisi Diminta"
    Catatan/Feedback Ketik feedback konstruktif, contoh: "RPP sudah cukup baik. Tambahkan lebih banyak variasi metode pembelajaran."

    Langkah 5: Simpan Evaluasi

    1. Klik tombol "Simpan Evaluasi"
    2. Sistem akan mencatat evaluasi dengan timestamp otomatis
    3. Notifikasi otomatis akan dikirim ke Guru dengan feedback Anda

    Contoh Feedback Konstruktif

    ✅ Baik: "RPP sudah komprehensif dengan alokasi waktu yang jelas. Pastikan media pembelajaran mencakup multimedia interaktif untuk meningkatkan engagement siswa."

    ❌ Kurang baik: "RPP kurang bagus. Perbaiki."

    Panduan Monitoring Kelas

    Akses Monitoring Kelas

    1. Login sebagai Kepala Sekolah atau Tim Penilai
    2. Buka menu "Monitoring Kelas" atau "Kunjungan Kelas"
    3. Klik tombol "Buat Monitoring Baru"

    Form Monitoring Kelas

    Isi form berikut:

    Field Deskripsi
    Guru Pilih nama guru yang ingin diobservasi
    Kelas Pilih kelas tempat pengajaran
    Mata Pelajaran Sistem auto-fill dari data guru
    Tanggal & Jam Pilih tanggal dan waktu kunjungan
    Catatan Observasi Tulis hasil observasi Anda

    Penilaian 6 Aspek Pembelajaran

    Sistem akan menampilkan 6 aspek penilaian dengan skala 1-5:

    1. Penguasaan Materi — Seberapa mendalam guru menguasai materi yang diajarkan
    2. Metode Pembelajaran — Kesesuaian metode dengan kompetensi dan usia siswa
    3. Penggunaan Media — Efektivitas penggunaan media/alat pembelajaran
    4. Pengelolaan Kelas — Kontrol dan manajemen kelas guru
    5. Interaksi dengan Siswa — Kemampuan guru berinteraksi dan melibatkan siswa
    6. Ketepatan Waktu — Manajemen alokasi waktu sesuai rencana

    Memberikan Nilai

    1. Untuk setiap aspek, pilih rating dari tombol 1-5 ⭐
    2. Warna akan berubah: Hijau (baik) hingga Merah (perlu perbaikan)
    3. Anda bisa menambah catatan per aspek (opsional)

    Simpan & Selesai

    1. Setelah mengisi semua aspek, klik "Simpan Monitoring"
    2. Sistem akan menghasilkan Laporan Monitoring Otomatis dengan:
    3. Skor rata-rata dari 6 aspek
    4. Grafik trend dari kunjungan sebelumnya (jika ada)
    5. Rekomendasi pengembangan guru

    Tips untuk Penilai

    📌 Jangan hanya fokus pada kesalahan — Catat juga hal positif yang dilakukan guru
    📌 Gunakan bahasa konstruktif — Feedback harus membangun, bukan meruntuhkan
    📌 Kunjungi min. 2x per semester — Untuk melihat trend dan progress guru
    📌 Konsultasi dengan guru — Setelah monitoring, diskusi untuk perbaikan bersama

    Pertanyaan Umum (FAQ)

    ❓ Bagaimana jika file RPP saya terlalu besar (> 5 MB)?

    Jawab: Kompres file terlebih dahulu menggunakan: - Software: WinRAR, 7-Zip (Windows) atau Archive Utility (Mac) - Online: TinyPDF, Smallpdf.com - Atau pisahkan menjadi beberapa file lebih kecil

    ❓ Format file apa saja yang bisa diupload?

    Jawab: Hanya format berikut yang diterima: - 📄 PDF (.pdf) - 📋 Word (.doc, .docx)

    File gambar (JPG, PNG) atau format lain tidak diterima.

    ❓ Berapa lama waktu evaluasi RPP?

    Jawab: Biasanya Tim Penilai akan mengevaluasi dalam 3-7 hari kerja setelah upload. Anda akan menerima notifikasi saat evaluasi selesai.

    ❓ Bisakah saya mengedit RPP setelah upload?

    Jawab: Tidak bisa mengedit file yang sudah upload. Jika ada kesalahan, hubungi Admin untuk dihapus terlebih dahulu, lalu upload ulang. Atau jika diminta revisi, upload versi terbaru dengan nama file berbeda.

    ❓ Bagaimana saya tahu ada feedback dari Tim Penilai?

    Jawab: Anda akan menerima notifikasi otomatis saat ada feedback. Cek: - 🔔 Ikon notifikasi di bagian atas aplikasi - 📧 Email (jika email notification aktif) - 💬 Telegram (jika Telegram notification aktif)

    ❓ Apakah nilai RPP mempengaruhi gaji saya?

    Jawab: Kebijakan penggunaan nilai evaluasi RPP ditentukan oleh sekolah/manajemen HR. Hubungi bagian Tata Usaha atau Kepala Sekolah untuk informasi lebih lanjut.

    ❓ Bisakah saya lihat RPP guru lain?

    Jawab: Tergantung peran Anda: - Guru: Hanya bisa lihat RPP milik sendiri - Wali Kelas: Bisa lihat RPP semua guru di kelasnya - Tim Penilai: Bisa lihat semua RPP untuk evaluasi - Kepala Sekolah: Bisa lihat semua RPP

    ❓ Bagaimana jika ada monitoring kelas yang tidak akurat?

    Jawab: Hubungi Kepala Sekolah atau Tim Penilai langsung untuk diskusi. Sistem tidak menyediakan fitur ajuan banding, tapi bisa diminta review kembali secara informal.
