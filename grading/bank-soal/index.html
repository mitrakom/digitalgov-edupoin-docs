    Pengenalan Singkat

    Apa itu Bank Soal?

    Bank Soal adalah pusat arsip dokumen soal ujian dan tugas yang dikelola oleh Guru Wali. Fitur ini membantu:

    • 📁 Menyimpan arsip soal dalam satu tempat terpusat per mata pelajaran
    • 📊 Mengorganisir soal berdasarkan jenis (UTS, UAS, Ulangan Harian, Kuis)
    • 🔍 Memudahkan pencarian dan referensi soal di semester berikutnya
    • ✅ Memastikan kualitas dan konsistensi soal antar tahun

    Siapa yang Menggunakan?

    Peran Fungsi
    Guru Wali Membuat, mengedit, mempublikasikan, dan mengarsipkan soal
    Wali Kelas Melihat dan mereferensikan soal untuk keperluan evaluasi
    Kesiswaan Akses view-only untuk monitoring dan referensi
    Tim Penilai Akses view-only untuk evaluasi kualitas soal
    Kepala Sekolah Monitoring dan validasi arsip soal di sekolah

    Akses Modul Bank Soal

    Menavigasi ke Bank Soal

    Setelah login:

    1. Buka menu sidebar "Bank Soal" (atau "Daftar Soal")
    2. Klik untuk membuka halaman daftar soal
    3. URL: https://edupoin.sekolah.id/app/bank-soal/daftar

    Tampilan Awal

    Halaman Bank Soal menampilkan:

    • Tombol "+ Soal Baru" — Untuk membuat soal baru (hanya untuk Guru Wali)
    • Filter Panel — Untuk mencari soal berdasarkan:
    • Mata Pelajaran (dropdown)
    • Kelas (opsional)
    • Jenis Soal (UTS, UAS, Ulangan Harian, Kuis)
    • Semester (1 atau 2)
    • Status (Draft, Published, Archived)
    • Tabel Daftar Soal — Menampilkan semua soal yang dapat diakses

    Panduan Guru Wali: Membuat & Mengelola Soal

    Langkah 1: Buat Soal Baru

    1. Klik tombol "+ Soal Baru" atau "+ Tambah"
    2. Sebuah modal/form akan muncul dengan field:
    Field Keterangan
    Mata Pelajaran Pilih mapel yang Anda ajarkan (dropdown)
    Kelas Opsional — pilih kelas tertentu atau kosongkan untuk semua
    Semester Pilih semester (1 atau 2)
    Judul Soal Contoh: "UTS Matematika Semester 1 - Perpangkatan"
    Deskripsi Opsional — catatan, KD, atau tingkat kesulitan
    Jenis Soal Pilih: UTS, UAS, Ulangan Harian, atau Kuis
    File Soal Upload file (PDF, Word; max 5 MB)

    Langkah 2: Simpan sebagai Draft

    1. Setelah mengisi form, klik "Simpan sebagai Draft"
    2. Soal Anda akan tersimpan dengan status "Draft" (belum dipublikasikan)
    3. Status Draft memungkinkan Anda untuk:
    4. ✏️ Edit soal sebelum dipublikasikan
    5. 🗑️ Hapus soal jika belum dipublikasikan
    6. 👀 Review kembali sebelum go-live

    Langkah 3: Publikasikan Soal

    Ketika soal sudah siap untuk digunakan:

    1. Buka soal yang statusnya "Draft"
    2. Klik tombol "Publikasikan" atau "Publish"
    3. Soal akan berubah status menjadi "Published"
    4. Status Published berarti:
    5. ✅ Soal aktif dan dapat direferensikan oleh user lain
    6. 🔒 Soal tidak dapat dihapus (hanya bisa diarsipkan)
    7. 📝 Metadata publikasi tercatat otomatis

    Langkah 4: Arsipkan Soal Lama

    Ketika soal sudah tidak digunakan lagi:

    1. Buka soal dengan status "Published"
    2. Klik tombol "Arsipkan" atau "Archive"
    3. Soal akan berubah status menjadi "Archived"
    4. Status Archived berarti:
    5. 🚫 Soal tidak lagi direferensikan untuk penggunaan baru
    6. 📚 Tetap tersimpan untuk records/sejarah
    7. 🔍 Dapat dicari kembali dengan filter "Status: Archived"

    Langkah 5: Edit & Hapus

    Mengedit Soal: - Hanya soal dengan status "Draft" yang dapat diedit - Klik tombol "Edit", ubah field, lalu "Simpan" - Soal Published tidak dapat diedit (harus diarsipkan dan buat baru)

    Menghapus Soal: - Hanya soal dengan status "Draft" yang dapat dihapus - Klik tombol "Hapus" (icon tempat sampah) - Konfirmasi, dan soal akan dihapus permanen - Soal Published/Archived tidak dapat dihapus (immutability rule)

    Tips Guru Wali

    ✅ Gunakan Judul Deskriptif — "UTS MTK Desember 2025 Kelas XI IPA" lebih baik daripada "UTS"
    ✅ Lengkapi Deskripsi — Tuliskan KD, CPL, atau tingkat kesulitan agar mudah dicari
    ✅ Publikasikan Tepat Waktu — Publikasikan sebelum semester dimulai
    ✅ Arsipkan Berkala — Arsipkan soal lama agar tampilan tetap rapi
    ✅ Konsistensi Semester — Pastikan semester dipilih dengan benar sesuai kalender akademik

    Panduan Wali Kelas: Melihat Arsip Soal

    Mengakses Bank Soal

    1. Login sebagai Wali Kelas
    2. Buka menu "Bank Soal" di sidebar
    3. Filter soal sesuai kebutuhan

    Fitur untuk Wali Kelas

    Wali Kelas hanya memiliki akses "View" (hanya dapat melihat):

    • 👀 Melihat semua soal Published
    • 🔍 Memfilter soal berdasarkan mapel, kelas, semester, dan jenis
    • 📥 Download file soal (jika diperlukan)
    • ❌ TIDAK dapat mengedit, hapus, atau publikasikan soal

    Use Case untuk Wali Kelas

    Wali Kelas menggunakan Bank Soal untuk: - Referensi saat evaluasi kinerja guru - Memahami jenis soal yang diberikan per mata pelajaran - Monitoring kualitas soal di kelasnya - Persiapan parent-teacher conference

    Panduan Kesiswaan & Tim Penilai: Akses Referensi

    Akses untuk Kesiswaan

    Kesiswaan hanya dapat: - 👀 Melihat soal Published - 🔍 Mencari soal - 📊 Melihat metadata (guru pembuat, tanggal publikasi)

    Use Case: - Monitoring kualitas soal di sekolah - Evaluasi konsistensi soal antar guru - Input untuk audit mutu pendidikan

    Akses untuk Tim Penilai

    Tim Penilai hanya dapat: - 👀 Melihat soal Published - 📝 Memberikan catatan evaluasi (fitur future) - 📊 Melakukan penilaian konten soal

    Use Case: - Evaluasi alignment soal dengan KD (Kompetensi Dasar) - Penilaian HOTS (Higher Order Thinking Skills) - Rekomendasi perbaikan soal

    Pertanyaan Umum (FAQ)

    Q: Bagaimana jika saya ingin mengedit soal yang sudah Published?

    A: Soal Published tidak dapat diedit. Anda harus: 1. Arsipkan soal lama → Klik "Arsipkan" 2. Buat soal baru dengan perbaikan → Klik "+ Soal Baru" 3. Publikasikan soal baru

    Ini adalah fitur immutability untuk menjaga integritas record.

    Q: Apakah semua guru dapat melihat soal guru lain?

    A: - Published soal → Dapat dilihat oleh Wali Kelas, Kesiswaan, Tim Penilai, Kepala Sekolah - Draft soal → Hanya bisa dilihat oleh pembuat (Guru Wali) - Archived soal → Dapat dicari oleh semua user dengan filter "Archived"

    Q: Apakah ada batasan jumlah soal?

    A: Tidak ada batasan jumlah soal per guru. Namun disarankan: - Minimal 1 soal per mapel per semester - Maksimal upload 10 file per bulan (untuk manajemen storage)

    Q: Apa bedanya Draft, Published, dan Archived?

    Status Edit? Terlihat Aksi
    Draft ✅ Ya Hanya pembuat Edit, Publikasikan, Hapus
    Published ❌ Tidak Semua user Arsipkan, Download
    Archived ❌ Tidak Semua user (filter) Lihat, Download

    Q: File soal saya gagal upload, apa solusinya?

    A: Periksa: - ✅ Format file: PDF, DOC, atau DOCX (bukan ZIP, RAR, dll) - ✅ Ukuran file: Maksimal 5 MB - ✅ Koneksi internet: Stabil dan cukup cepat - ✅ Browser: Update ke versi terbaru

    Jika masih gagal, hubungi TU atau Admin.

    Q: Bagaimana cara backup soal saya?

    A: Soal tersimpan di cloud server EduPoin. Untuk backup tambahan: 1. Buka soal Published 2. Klik "Download" untuk mengunduh file original 3. Simpan di komputer atau cloud pribadi (Google Drive, OneDrive)

    Q: Bisakah saya membagikan soal ke guru lain?

    A: Fitur share belum tersedia di versi ini. Solusi alternatif: - Publikasikan soal → Guru lain dapat melihat dan download - Hubungi TU → Untuk share private antar guru
