    Pengenalan Singkat

    Apa itu Modul Tugas?

    Modul Tugas adalah sistem untuk membuat, mengelola, dan menilai tugas/PR yang diberikan kepada siswa. Fitur ini membantu:

    • 📝 Guru membuat tugas terstruktur per kelas dan mata pelajaran
    • 📅 Menetapkan tanggal pemberian dan deadline
    • 🎯 Menilai tugas siswa dan mencatat nilai
    • 📊 Melacak progress penilaian (siswa mana saja yang sudah dinilai)
    • 📈 Nilai tugas otomatis masuk ke perhitungan nilai akhir semester

    Siapa yang Menggunakan?

    Peran Fungsi
    Guru Wali Membuat tugas, mengaktifkan, menilai, dan menyelesaikan
    Wali Kelas Melihat daftar tugas, menilai, dan membantu monitoring

    Akses Modul Tugas

    Menavigasi ke Tugas

    Setelah login sebagai Guru Wali atau Wali Kelas:

    1. Buka menu sidebar "Tugas" (atau "Manajemen Tugas")
    2. Halaman akan menampilkan daftar tugas
    3. URL: https://edupoin.sekolah.id/app/nilai/tugas

    Tampilan Awal

    • Tombol "+ Tugas Baru" — Untuk membuat tugas baru (Guru Wali only)
    • Filter Panel:
    • Kelas (dropdown)
    • Mata Pelajaran (dropdown)
    • Semester (1 atau 2)
    • Tabel Daftar Tugas — Menampilkan:
    • Judul Tugas
    • Mata Pelajaran & Kelas
    • Tanggal Pemberian & Deadline
    • Status (Draft, Aktif, Selesai)
    • Progress Penilaian (contoh: "12/30 dinilai")

    Panduan Guru Wali: Membuat Tugas

    Langkah 1: Buka Form Buat Tugas

    1. Klik tombol "+ Tugas Baru" atau "+ Tambah Tugas"
    2. Sebuah modal/form akan muncul

    Langkah 2: Isi Informasi Tugas

    Field Cara Isi
    Mata Pelajaran Pilih dari dropdown (hanya mapel yang Anda ajarkan)
    Kelas Pilih kelas yang akan menerima tugas
    Semester Pilih 1 atau 2
    Judul Tugas Contoh: "PR Bab 5 Fungsi Linear"
    Deskripsi Opsional — ketik instruksi/detail tugas (contoh: "Kerjakan soal hal 45-50")
    File Lampiran Opsional — upload soal/referensi (PDF, Word, max 10 MB)
    Tanggal Diberikan Pilih tanggal ketika tugas dibagikan
    Deadline Pilih tanggal maksimal pengumpulan (opsional)
    Nilai Maksimal Default: 100. Edit jika perlu berbeda (contoh: 50 untuk kuis pendek)

    Langkah 3: Simpan sebagai Draft

    1. Klik "Simpan sebagai Draft"
    2. Tugas akan tersimpan dengan status "Draft" (belum aktif)
    3. Anda dapat:
    4. ✏️ Edit tugas sebelum diaktifkan
    5. 🗑️ Hapus tugas
    6. 🚀 Mengaktifkannya kapan saja

    Status Tugas

    Status Arti
    Draft Tugas sedang disiapkan, belum aktif untuk dinilai
    Aktif Tugas sedang berlangsung, siswa dapat dinilai
    Selesai Tugas sudah ditutup, tidak ada penilaian baru

    Panduan Guru Wali: Mengaktifkan Tugas

    Mengapa Harus Diaktifkan?

    Ketika tugas diaktifkan: - ✅ Sistem otomatis membuat record penilaian untuk setiap siswa di kelas tersebut - 📝 Field penilaian menjadi tersedia untuk diisi - 📊 Progress penilaian mulai terhitung

    Langkah 1: Aktivasi Tugas

    1. Di halaman Daftar Tugas, temukan tugas dengan status "Draft"
    2. Klik tombol "Aktifkan" atau "Mulai Penilaian"
    3. Sebuah modal konfirmasi akan muncul:
    4. "Mengaktifkan tugas ini akan membuat record penilaian untuk X siswa. Lanjutkan?"
    5. Klik "Ya, Aktifkan"

    Langkah 2: Verifikasi

    Setelah aktivasi: - Tugas status berubah menjadi "Aktif" - Progress penilaian mulai tampil (contoh: "0/30 dinilai") - Tombol "Nilai Tugas" atau "Masukkan Nilai" menjadi aktif

    Panduan Guru Wali & Wali Kelas: Menilai Tugas

    Langkah 1: Buka Panel Penilaian

    1. Di halaman Daftar Tugas, klik pada tugas dengan status "Aktif"
    2. Atau klik tombol "Masukkan Nilai" / "Nilai Siswa"
    3. Halaman penilaian akan terbuka dengan tabel siswa

    Langkah 2: Lihat Daftar Siswa

    Tabel penilaian menampilkan:

    Kolom Isi
    Nama Siswa Nama lengkap siswa di kelas
    Nilai Field input untuk memasukkan nilai (0-100)
    Catatan Field text untuk catatan (opsional)
    Status Penilaian Belum Dinilai / Dinilai

    Langkah 3: Masukkan Nilai

    1. Klik field "Nilai" pada baris siswa
    2. Ketik nilai (0-100)
    3. Opsional: ketik catatan di field "Catatan" (contoh: "Bagus, tapi ada kesalahan no 5")
    4. Nilai akan otomatis tersimpan (auto-save)

    Langkah 4: Lihat Progress

    • Progress Bar menampilkan: "12 dari 30 siswa sudah dinilai" (40%)
    • Sistem otomatis menghitung rata-rata nilai tugas

    Tips Guru Saat Menilai

    ✅ Inputkan Nilai Konsisten — Gunakan skala penilaian yang sama (0-100)
    ✅ Tambahkan Catatan — Catatan membantu siswa untuk improvement
    ✅ Lakukan Secara Bertahap — Tidak harus selesai dalam sekali duduk
    ✅ Pantau Progress — Lihat persentase siswa yang sudah dinilai

    Panduan Menyelesaikan Tugas

    Kapan Harus Menyelesaikan?

    Setelah semua siswa dinilai atau deadline sudah lewat:

    1. Di halaman Daftar Tugas, temukan tugas dengan status "Aktif"
    2. Klik tombol "Selesaikan" atau "Tutup Penilaian"
    3. Konfirmasi akan muncul:
    4. "Menyelesaikan tugas ini akan menutup penilaian. Anda masih bisa edit nilai, tapi tidak bisa tambah siswa baru. Lanjutkan?"
    5. Klik "Ya, Selesaikan"

    Setelah Tugas Selesai

    • Status tugas berubah menjadi "Selesai"
    • Rata-rata nilai tugas tersimpan otomatis
    • Nilai masuk ke komponen penilaian untuk perhitungan nilai akhir
    • Anda masih bisa melihat/edit nilai, tapi tidak bisa menambah siswa baru

    Pertanyaan Umum (FAQ)

    Q: Apakah saya bisa mengubah nilai tugas setelah "Selesai"?

    A: Ya! Anda masih bisa mengubah nilai: 1. Buka tugas yang sudah "Selesai" 2. Klik "Masukkan Nilai" atau panel penilaian 3. Edit nilai siswa tertentu 4. Nilai otomatis tersimpan dan ter-update di perhitungan nilai akhir

    Q: Bagaimana jika ada siswa baru masuk setelah tugas diaktifkan?

    A: - Sebelum "Selesai": Anda dapat menambah nilai di tabel (field akan tersedia) - Setelah "Selesai": Hubungi Admin untuk tambah record penilaian siswa baru

    Q: Apakah Wali Kelas bisa membuat tugas?

    A: Tidak. Hanya Guru Wali yang bisa membuat tugas. Wali Kelas hanya bisa: - 👀 Melihat daftar tugas - 🎯 Menilai tugas - 📊 Melihat progress penilaian

    Q: Apa bedanya "Nilai Maksimal" 100 vs 50?

    A: - Nilai Maksimal 100: Nilai 80 akan dihitung sebagai 80 (80%) - Nilai Maksimal 50: Nilai 40 akan dihitung sebagai 40 × (100/50) = 80 (80%)

    Gunakan nilai maksimal berbeda jika ingin kuis pendek atau tugas ringan.

    Q: Bagaimana jika saya keliru mengaktifkan tugas?

    A: - Hubungi Admin untuk reset status tugas ke "Draft" - Atau buat tugas baru dengan judul berbeda

    Q: Apakah rata-rata nilai tugas otomatis dihitung?

    A: Ya! Sistem otomatis menghitung: - Rata-rata nilai tugas = (jumlah nilai semua siswa) / (jumlah siswa) - Rata-rata tersebut digunakan di formula perhitungan nilai akhir

    Q: File lampiran tugas bisa diunduh siswa?

    A: Dalam versi ini, file hanya tersimpan untuk referensi. Untuk bagikan file ke siswa: - Alternatif 1: Tulis link Google Drive di field "Deskripsi" - Alternatif 2: Bagikan file via WhatsApp/Email terpisah - Alternatif 3: Tunggu fitur download di versi berikutnya
