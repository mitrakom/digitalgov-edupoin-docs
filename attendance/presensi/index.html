    Pengenalan Singkat

    Modul Presensi adalah fitur di EduPoin untuk mencatat kehadiran siswa secara digital. Fitur ini dirancang untuk memudahkan Guru melakukan presensi cepat di kelas dengan tampilan yang sederhana dan responsif di perangkat mobile.

    Status Kehadiran

    Setiap siswa dapat memiliki status sebagai berikut:

    Status Simbol Arti
    Hadir 🟢 Siswa hadir sesuai jadwal
    Sakit 🟡 Siswa tidak hadir karena sakit (dengan bukti surat/pemberitahuan orang tua)
    Izin 🟠 Siswa tidak hadir atau keluar sekolah karena alasan resmi. Gunakan untuk dua kondisi: (a) siswa izin keluar sementara di tengah hari, atau (b) siswa sama sekali tidak datang ke sekolah karena punya izin resmi (acara keluarga, lomba, dll). Tambahkan keterangan untuk membedakan keduanya.
    Alpha 🔴 Siswa tidak hadir tanpa keterangan apapun

    Benefit Menggunakan Modul Presensi

    ✓ Cepat: Input massal hanya dengan klik radio button per siswa
    ✓ Akurat: Tidak perlu hafal nama siswa, nama sudah tertera
    ✓ Aman: Data tersimpan otomatis dengan timestamp
    ✓ Transparan: Orang tua dapat melihat notifikasi jika siswa tidak hadir
    ✓ Mobile-Friendly: Bisa digunakan di smartphone bahkan di kelas

    Akses Modul Presensi

    Cara Login

    1. Buka aplikasi EduPoin di browser
    2. Masukkan Username/Email dan Password Anda
    3. Klik tombol Login

    Masuk ke Halaman Presensi

    Untuk Guru/Guru Wali/Wali Kelas:

    1. Setelah login, akan muncul menu utama
    2. Cari menu "Presensi" di sidebar (menu kiri)
    3. Klik menu Presensi
    4. Anda akan masuk ke halaman input presensi

    Shortcut Direct: - Ketik URL: https://edupoin.sekolah.id/app/presensi (sesuaikan domain)

    Tahap 3: Tandai Status Kehadiran Siswa

    Langkah-langkah:

    1. Untuk setiap siswa, pilih salah satu status:
    2. Hadir (⭕): Klik jika siswa hadir
    3. Sakit (⚪): Klik jika siswa tidak hadir karena sakit
    4. Izin (⚪): Klik jika siswa tidak hadir atau keluar sekolah karena alasan resmi yang diizinkan — baik izin keluar sementara di tengah hari maupun izin tidak masuk sekolah sama sekali. Tambahkan catatan di kolom Keterangan untuk membedakan keduanya.

    5. Tidak dipilih = Alpha (🔴): Otomatis jika tidak ditandai

    6. Contoh cara klik: 

      Siswa "Budi Santoso" → Klik radio button "Hadir"
Siswa "Ani Wijaya" → Klik radio button "Sakit"
Siswa "Chandra Kusuma" → Klik radio button "Izin"
Siswa "Dewi Rahayu" → Klik radio button "Hadir"
Siswa "Eka Putra Wijaya" → Tidak diklik = Alpha

    Tahap 4: Gunakan Fitur Shortcut (Opsional)

    Tombol "Mark All: Hadir" - Klik untuk otomatis menandai semua siswa sebagai Hadir - Berguna jika seluruh kelas hadir - Anda masih bisa edit siswa individual setelahnya

    Tombol "Mark All: Sakit" - Klik untuk otomatis menandai semua siswa sebagai Sakit - Jarang digunakan, biasanya hanya untuk kelas libur mendadak

    Tombol "Reset" - Klik untuk membatalkan semua pilihan dan mulai ulang - Status kembali ke kosong (semua Alpha)

    Tahap 5: Simpan Presensi

    Sebelum simpan, pastikan: - ✅ Sudah menandai minimal 1 siswa dengan status - ✅ Status waktu menunjukkan "✅ Jam Berlangsung" - ✅ Data sudah benar

    Cara simpan: 1. Klik tombol "💾 Simpan Presensi" (biru/hijau) 2. Tunggu proses loading (ada animasi loading) 3. Akan muncul notifikasi sukses: "✓ Presensi tersimpan (26 siswa)" 4. Halaman akan kembali ke daftar jadwal

    Tahap 6: Selesai!

    Presensi untuk jam pelajaran tersebut sudah tersimpan dan tidak bisa diubah (kecuali Wali Kelas melakukan koreksi).

    Untuk jam berikutnya, ulangi dari Tahap 1 dengan jadwal berikutnya.

    Panduan untuk Wali Kelas

    Akses Modul Presensi

    Wali Kelas memiliki akses khusus untuk melakukan koreksi/verifikasi presensi kelas mereka.

    Bagian Khusus Wali Kelas:

    1. Masuk ke menu Presensi → Verifikasi Presensi
    2. Pilih kelas yang Anda tandai wali
    3. Pilih tanggal yang ingin diverifikasi
    4. Sistem akan menampilkan daftar presensi dari hari tersebut

    Fitur Koreksi Presensi

    Sebagai Wali Kelas, Anda bisa:

    ┌──────────────────────────────────────────────────┐
│ VERIFIKASI PRESENSI KELAS X-A                   │
│ Tanggal: Senin, 14 April 2026                   │
├──────────────────────────────────────────────────┤
│                                                  │
│ Jam 1 (08:00-09:00) - Matematika                │
│ ├─ Budi Santoso: Hadir ✅ [Edit]                │
│ ├─ Ani Wijaya: Sakit ✅ [Edit]                  │
│ ├─ Chandra Kusuma: Izin ✅ [Edit]               │
│ ├─ Dewi Rahayu: Hadir ✅ [Edit]                 │
│ └─ Eka Putra Wijaya: Alpha ⚠️ [Edit]            │
│                                                  │
│ Jam 2 (09:15-10:15) - Bahasa Inggris            │
│ ├─ Budi Santoso: Hadir ✅ [Edit]                │
│ └─ ...                                          │
│                                                  │
└──────────────────────────────────────────────────┘

    Cara Edit: 1. Klik tombol [Edit] pada siswa yang ingin diubah 2. Pilih status yang benar 3. Klik Simpan Perubahan 4. Notifikasi akan muncul: "✓ Presensi diperbarui"

    Tips Wali Kelas

    • Periksa Alpha: Perhatikan siswa dengan status Alpha (🔴). Jika ada yang harusnya Izin/Sakit, lakukan koreksi
    • Periksa Izin: Bandingkan dengan data di modul Perizinan untuk memastikan akurasi
    • Laporan Harian: Setiap akhir hari, review presensi kelas Anda untuk memastikan semua benar

    Panduan untuk Kesiswaan

    Akses Laporan Presensi

    Kesiswaan dapat melihat laporan presensi keseluruhan untuk keperluan monitoring dan analisis.

    Cara Akses:

    1. Masuk menu Presensi → Laporan Rekapitulasi
    2. Pilih Rentang Tanggal (mulai - selesai)
    3. Pilih Kelas (opsional) atau Semua Kelas
    4. Klik Tampilkan Laporan

    Tips & Trik Menggunakan Aplikasi

    1. Gunakan Smartphone untuk Input di Kelas

    Keuntungan: - Lebih fleksibel bergerak di kelas - Tidak perlu ke kantor dulu - Real-time bisa lihat daftar siswa

    Tips: - Gunakan koneksi WiFi yang stabil - Jangan lupa lock screen jika meninggalkan hp - Pastikan battery cukup sebelum jam pelajaran

    2. Markdown/Sort Data Siswa

    Jika ada siswa yang belum datang: - Jangan langsung klik Alpha - Tunggu 5-10 menit untuk siswa yang terlambat - Gunakan fitur "Refresh Daftar Siswa" jika ada perubahan (siswa masuk/keluar)

    3. Batching Input untuk Banyak Kelas

    Skenario: Anda mengajar 5 kelas sehari

    Cara Efisien: 1. Masuk jam 1: Input Kelas X-A 2. Masuk jam 2: Input Kelas X-B (buka form baru) 3. Jangan membuka lebih dari 2 form sekaligus (bisa error)

    4. Koreksi Data

    Jika salah input: - Sebagai Guru: Hubungi Wali Kelas atau Kesiswaan untuk koreksi - Sebagai Wali Kelas: Gunakan fitur "Edit" di menu Verifikasi Presensi

    Jangan: - ❌ Menghapus data presensi sendiri - ❌ Menginput presensi hari lalu (sudah locked)

    5. Notifikasi Otomatis ke Orang Tua

    Bagaimana cara kerjanya: - Jika siswa Alpha (tidak hadir), sistem otomatis kirim notifikasi Telegram ke orang tua - Notifikasi hanya dikirim jika tidak ada data Izin/Sakit di sistem perizinan - Notifikasi dikirim saat jam pelajaran selesai

    Tips: - Pastikan orang tua sudah terdaftar nomor Telegram di sistem - Jika orang tua tidak terima notifikasi, hubungi TU untuk verifikasi nomor Telegram

    Pertanyaan Umum (FAQ)

    Q1: Bagaimana jika saya lupa input presensi saat jam pelajaran?

    A: - Jika belum melampaui jam selesai: Anda masih bisa input dengan klik jadwal tersebut - Jika sudah melampaui jam selesai: Form akan terkunci, hubungi Wali Kelas atau Kesiswaan untuk meminta bantuan input

    Q2: Apa bedanya status "Izin" dan "Sakit"?

    A: - Izin: Siswa tidak hadir atau keluar sekolah karena alasan resmi yang diizinkan. Status ini mencakup dua kondisi: - (a) Izin keluar sementara: Siswa masuk sekolah, tapi di tengah hari izin keluar (misalnya: ke dokter, mengikuti lomba di luar kota, keperluan mendesak). Biasanya ada data di modul Perizinan BK. - (b) Izin tidak masuk sekolah: Siswa sama sekali tidak datang ke sekolah pada hari itu karena punya izin resmi (misalnya: acara keluarga, pernikahan saudara, mengikuti perlombaan). Ada surat atau pemberitahuan dari orang tua. - Sakit: Siswa tidak bisa hadir karena sakit. Bisa dengan surat dokter atau pemberitahuan orang tua melalui WhatsApp/telepon.

    Tips menggunakan field Keterangan: - Izin keluar sementara → tulis "Keluar: periksa dokter pukul 10:00" - Izin tidak sekolah → tulis "Tidak masuk: menghadiri acara pernikahan saudara" - Sakit → tulis "Sakit demam, ada surat dokter" (opsional)

    Q3: Bagaimana jika siswa datang terlambat?

    A: - Tetap input status "Hadir" - Sistem tidak membedakan hadir tepat waktu atau terlambat (evaluasi terpisah di modul lain) - Catat waktu datang jika diperlukan di field Keterangan (opsional)

    Q4: Apa itu status "Alpha"?

    A: - Alpha = siswa tidak hadir tanpa keterangan apapun - Jika Anda tidak menandai status siswa, sistem otomatis set ke Alpha - Status Alpha akan memicu notifikasi Telegram ke orang tua siswa

    Q5: Bagaimana cara ubah presensi yang sudah tersimpan?

    A: - Sebagai Guru: Tidak bisa mengubah sendiri. Hubungi Wali Kelas atau Kesiswaan - Sebagai Wali Kelas: Masuk menu Presensi → Verifikasi Presensi, cari siswa, klik [Edit], ubah status, simpan

    Q6: Berapa waktu toleransi untuk input presensi?

    A: - Presensi bisa diisi 5 menit sebelum jam pelajaran dimulai hingga 5 menit setelah jam selesai - Contoh: Jam 08:00-09:00, Anda bisa input antara 07:55-09:05 - Setelah itu, form akan terkunci dan hanya Wali Kelas yang bisa edit

    Q7: Apakah bisa input presensi hari kemarin atau minggu lalu?

    A: - TIDAK, sistem tidak memperbolehkan input presensi hari-hari yang sudah lewat - Alasan: Untuk menjaga integritas data dan transparansi - Jika ada kesalahan, hubungi Wali Kelas atau Kesiswaan untuk koreksi

    Q8: Apa yang terjadi jika koneksi internet terputus saat input?

    A: - Jika terputus sebelum klik "Simpan": Data tidak tersimpan, ulangi dari awal - Jika terputus saat sedang menyimpan: Tunggu koneksi pulih, cek apakah sudah tersimpan - Tip: Pastikan koneksi WiFi stabil sebelum mulai input

    Q9: Bagaimana jika ada siswa yang tidak ada di daftar?

    A: - Kontak TU (Tata Usaha) untuk verifikasi - Kemungkinan: Siswa baru, belum terdaftar di kelas, atau status non-aktif - Jangan input data siswa sendiri

    Q10: Apakah presensi otomatis sync dengan sistem lain (perizinan, nilai, dll)?

    A: - Ya, sistem terintegrasi: - Status Alpha → Trigger notifikasi Telegram (jika tidak ada Izin/Sakit) - Status Izin → Cocok dengan data di modul Perizinan - Presensi otomatis masuk Laporan Kehadiran Tahunan - Proses sync berjalan otomatis, tidak perlu action manual

    Q11: Siapa yang bisa melihat data presensi saya?

    A: - Guru yang input: Hanya presensi kelas yang dia ajar - Wali Kelas: Semua presensi kelas yang dia tandai - Kesiswaan: Laporan rekapitulasi (tidak detail per guru) - Kepala Sekolah: Dashboard ringkasan dan monitoring guru - Orang Tua: Hanya notifikasi (jika siswa Alpha)

    Q12: Bagaimana jika saya ingin melihat laporan presensi siswa tertentu?

    A:

    Untuk Guru: - Masuk Presensi → History Presensi - Pilih siswa dan tanggal - Lihat detail presensi per hari

    Untuk Wali Kelas: - Masuk Presensi → Verifikasi Presensi - Pilih siswa untuk melihat history kehadiran

    Untuk Kesiswaan/Kepala Sekolah: - Masuk Presensi → Laporan Rekapitulasi - Filter berdasarkan siswa/kelas/tanggal

    Q13: Apakah ada reminder/notifikasi jika belum input presensi?

    A: - Belum ada di versi ini - Workaround: Buat reminder sendiri di kalender/alarm hp - Rencana: Fitur reminder akan ditambahkan di update mendatang

    Q14: Bagaimana cara print/export laporan presensi?

    A:

    Export ke Excel: - Masuk Presensi → Laporan Rekapitulasi - Klik tombol "📥 Export ke Excel" - File akan download ke perangkat Anda

    Print: - Buka file Excel yang sudah di-export - Gunakan fitur Print di Excel (Ctrl+P)

    Q15: Siapa yang bisa membantu jika ada masalah teknis?

    A:

    Masalah Umum: - Hubungi TU (Tata Usaha) atau Admin Sistem

    Masalah Perlu Koreksi Data: - Hubungi Wali Kelas (untuk koreksi presensi) atau Kesiswaan (untuk approval)

    Masalah Server/Aplikasi Error: - Hubungi Tim IT/Developer dengan screenshot error
