    Versi: 1.0
    Untuk: Tim Tata Usaha (TU), Admin Sekolah
    Tanggal: April 2026
    Status: Siap Digunakan

    Pengenalan Singkat

    Modul Data Guru adalah fitur di EduPoin untuk mengelola data guru dan tenaga pengajar di sekolah. Modul ini terintegrasi dengan sistem user management, sehingga setiap guru yang ditambahkan otomatis mendapatkan akun login dengan username dan password.

    🎯 Fitur Utama

    Fitur Deskripsi
    Tambah Guru Menambahkan guru baru beserta akun sistem otomatis
    Auto User Creation Sistem otomatis membuat user account saat guru ditambahkan
    Role Assignment Guru selalu mendapat role "Guru", plus "Wali Kelas" jika applicable
    Default Password Password default = NIP, dapat diubah saat penambahan
    Edit Data Guru Mengubah data identitas, status, dan role guru
    Wali Kelas Management Secara otomatis add/remove role "Wali Kelas" saat status diubah

    ✨ Manfaat Integrasi Akun Sistem

    ✓ Efisien: Tidak perlu membuat user terpisah, otomatis saat tambah guru
    ✓ Aman: Setiap guru punya akun dengan role "Guru" dan/atau "Wali Kelas"
    ✓ Fleksibel: Username dan password dapat diatur saat penambahan
    ✓ Dinamis: Role "Wali Kelas" otomatis di-sync saat status berubah
    ✓ Terintegrasi: Akun guru terhubung dengan fitur presensi, nilai, pelanggaran, RPP, dll

    Akses Modul Data Guru

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Guru

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri), cari "Guru" di bawah grup "Personil"
    3. Klik Guru
    4. Anda akan masuk ke halaman daftar guru

    Direct URL: 

    https://edupoin.sekolah.id/admin/gurus
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Menambahkan Guru Baru

    Langkah 1: Masuk ke Halaman Daftar Guru

    Ikuti petunjuk di bagian Akses Modul Data Guru

    Langkah 2: Klik Tombol "Tambah Guru"

    Di halaman daftar guru, Anda akan melihat tombol berwarna biru "+ Tambah Guru" di sudut kanan atas.

    ┌─────────────────────────────────────────────┐
│  [← Kembali]     Daftar Guru                │
├─────────────────────────────────────────────┤
│                        [+ Tambah Guru] ▼    │
│                                             │
│ Tabel daftar guru...                        │
└─────────────────────────────────────────────┘

    Klik tombol tersebut.

    Langkah 3: Isi Form Informasi Identitas

    Form akan terbuka dengan beberapa bagian yang dapat dilipat (collapsible). Mulai dari section "Informasi Identitas":

    Informasi Identitas (Wajib diisi)

    Field Keterangan Contoh Aturan
    Nama Guru Nama lengkap guru Ibu Siti Nurhaliza Wajib diisi, maksimal 255 karakter
    NIP Nomor Induk Pegawai 198505152010012004 Wajib, harus unik (tidak boleh duplikat)
    NUPTK Nomor Unik Pendidik Tenaga Kependidikan 1234567890987654 Opsional, harus unik jika diisi

    Contoh: 

    Nama Guru: Ibu Siti Nurhaliza
NIP: 198505152010012004
NUPTK: 1234567890987654

    Langkah 4: Isi Form Status Kepegawaian

    Klik atau expand section "Status Kepegawaian":

    Field Keterangan Pilihan Wajib
    Status Kepegawaian Status kepegawaian guru di sekolah • PNS
    • PPPK
    • Honorer
    • GTT    		 Ya (default: GTT)
    Wali Kelas Tandai jika guru ini adalah wali kelas Toggle: ON/OFF Ya

    📌 Penting Tentang "Wali Kelas": - Jika ON: Guru akan mendapat role "Wali Kelas" + "Guru" - Jika OFF: Guru hanya mendapat role "Guru" - Role dapat diubah nanti kapan saja dengan mengubah status ini

    Contoh: 

    Status Kepegawaian: PNS
Wali Kelas: ON ✓

    Langkah 5: Isi Form Akun Pengguna ⭐ (Penting!)

    INI ADALAH BAGIAN BARU — Setiap guru baru akan mendapat akun login. Expand section "Akun Pengguna":

    Field Keterangan Default Catatan
    Username Username untuk login guru NIP Jika kosong, akan otomatis = NIP. Harus unik.
    Password Password untuk login guru NIP Jika kosong, akan otomatis = NIP. Guru bisa ubah saat first login.
    Email Email guru (opsional) - Dapat diisi nanti, tidak wajib

    💡 Rekomendasi: - Kosongkan username & password untuk menggunakan NIP sebagai keduanya (simple & mudah diingat) - Atau isikan username custom jika ingin berbeda dari NIP - Password dapat direset kapan saja oleh admin

    📝 Contoh Pengisian Lengkap

    ┌──────────────────────────────────────────────────────┐
│ INFORMASI IDENTITAS                                  │
├──────────────────────────────────────────────────────┤
│ Nama Guru:           Ibu Siti Nurhaliza              │
│ NIP:                 198505152010012004              │
│ NUPTK:               1234567890987654                │
├──────────────────────────────────────────────────────┤
│ STATUS KEPEGAWAIAN                                   │
├──────────────────────────────────────────────────────┤
│ Status Kepegawaian:  PNS                             │
│ Wali Kelas:          ✓ ON                            │
├──────────────────────────────────────────────────────┤
│ AKUN PENGGUNA ⭐                                      │
├──────────────────────────────────────────────────────┤
│ Username:            (kosongkan = otomatis dari NIP) │
│ Password:            (kosongkan = otomatis dari NIP) │
│ Email:               siti@sekolah.id (opsional)     │
└──────────────────────────────────────────────────────┘

    Langkah 6: Simpan Data

    Setelah semua field wajib diisi:

    1. Scroll ke bawah
    2. Klik tombol "Simpan" (berwarna hijau)

    Apa yang terjadi otomatis: - ✅ Data guru disimpan ke database - ✅ User account dibuat dengan username dan password yang Anda tentukan (atau NIP jika kosong) - ✅ Role "Guru" otomatis di-assign - ✅ Role "Wali Kelas" di-assign jika Anda menandai checkbox tersebut - ✅ Notifikasi muncul dengan pesan sukses dan menampilkan username/password

    Langkah 7: Catat Kredensial

    Segera catat atau informasikan ke guru: 

    Username: 198505152010012004
Password: 198505152010012004

    ⚠️ PENTING: Notifikasi hanya ditampilkan sekali saat create. Jika guru lupa, admin dapat reset password melalui menu User Management.

    Panduan: Mengubah Data Guru

    Skenario 1: Mengubah Data Identitas atau Status Kepegawaian

    1. Buka halaman Daftar Guru
    2. Cari guru yang ingin diubah di tabel
    3. Klik nama guru atau ikon "Edit" (pensil)
    4. Ubah data sesuai kebutuhan
    5. Klik "Simpan Perubahan"

    Skenario 2: Menambahkan Role "Wali Kelas"

    1. Buka edit halaman guru
    2. Di section "Status Kepegawaian", toggle "Wali Kelas" menjadi ON
    3. Klik "Simpan Perubahan"
    4. ✅ Role "Wali Kelas" otomatis ditambahkan ke akun guru

    Skenario 3: Menghapus Role "Wali Kelas"

    1. Buka edit halaman guru
    2. Di section "Status Kepegawaian", toggle "Wali Kelas" menjadi OFF
    3. Klik "Simpan Perubahan"
    4. ✅ Role "Wali Kelas" otomatis dihapus, guru hanya punya role "Guru"

    Tips & Best Practice

    🎯 Keamanan & Password

    Praktik Alasan
    Gunakan NIP sebagai password default Mudah diingat, tapi sebaiknya guru ubah saat first login
    Jangan share password via email Beritahu langsung atau cetak saat create
    Reset password secara berkala Untuk keamanan akun jangka panjang

    📝 Penamaan & Konsistensi

    Praktik Contoh
    Gunakan nama lengkap (Gelar + Nama) ✓ Ibu Siti Nurhaliza
    ✗ Siti
    NIP harus sesuai dokumen resmi Hindari typo atau kesalahan input
    NUPTK optional, tapi usahakan lengkap Membantu identifikasi unik guru

    🔄 Workflow Rekomendasi

    Saat Penambahan Guru Baru:

    1. TU menerima dokumen guru (SK, identitas, dll)
    2. TU input data guru di EduPoin
    3. Sistem auto-generate username & password (= NIP)
    4. TU catat kredensial & informasikan ke guru
    5. Guru login & ubah password di form profil (first login)
    6. Guru siap menggunakan sistem

    Pertanyaan Umum (FAQ)

    ❓ Bagaimana cara reset password guru yang lupa?

    Jawab: Admin dapat mengakses menu "User Management" untuk reset password guru. Guru akan mendapat password baru yang sama dengan username (atau nilai lain sesuai kebijakan sekolah).

    ❓ Bisa tidak username guru berbeda dari NIP?

    Jawab: Bisa! Saat menambah guru, isikan username custom di field "Username" di section "Akun Pengguna". Contoh: siti.nurhaliza atau siti_guru. Pastikan username tersebut belum terdaftar.

    ❓ Apa bedanya guru biasa dengan guru wali kelas?

    Jawab: - Guru Biasa: Role "Guru" → dapat input presensi, nilai, pelanggaran - Wali Kelas: Role "Guru" + "Wali Kelas" → dapat juga verifikasi presensi, verifikasi pelanggaran ringan, lihat data keseluruhan kelasnya

    ❓ Bisa tidak guru memiliki dua peran wali kelas sekaligus?

    Jawab: Sistem EduPoin dirancang 1 wali kelas per kelas. Jika guru ingin menjadi wali kelas, tandai checkbox "Wali Kelas" = ON. Jika ada perubahan kelas, update di menu "Manajemen Kelas".

    ❓ Bagaimana cara menghapus akun guru?

    Jawab: Klik tombol "Hapus" (icon trash) di halaman edit guru. Data guru dan akunnya akan dihapus dari sistem. ⚠️ HATI-HATI: Tindakan ini tidak bisa diunduh. Gunakan hanya jika data entry salah atau guru resign.

    ❓ Apakah guru bisa login dari mana saja?

    Jawab: Ya. Guru dapat login dari laptop, tablet, atau smartphone asalkan ada koneksi internet ke URL sekolah. Direkomendasikan untuk keamanan, batasi akses dari IP sekolah saja (setting server).

    ❓ Bisakah satu user akun untuk dua guru?

    Jawab: Tidak direkomendasikan. Setiap guru harus memiliki akun unik untuk audit trail dan akuntabilitas. Jika kebutuhan spesifik, hubungi admin/kepala TI.
