    Pengenalan Singkat

    Modul Data Siswa adalah fitur di EduPoin untuk mengelola data siswa di sekolah. Modul ini terintegrasi dengan sistem user management, sehingga setiap siswa yang ditambahkan otomatis mendapatkan akun login dengan username dan password.

    🎯 Fitur Utama

    Fitur Deskripsi
    Tambah Siswa Menambahkan siswa baru beserta akun sistem otomatis
    Auto User Creation Sistem otomatis membuat user account saat siswa ditambahkan
    Default Password Password default = username, dapat diubah saat penambahan
    Edit Data Siswa Mengubah data identitas, akademik, dan akun siswa
    Reset Password Mengembalikan password ke default (username) kapan saja
    Hapus Data Siswa Menghapus data siswa dan akun sistemnya

    ✨ Manfaat Integrasi Akun Sistem

    ✓ Efisien: Tidak perlu membuat user terpisah, otomatis saat tambah siswa
    ✓ Aman: Setiap siswa hanya punya akun dengan role "Siswa"
    ✓ Fleksibel: Username dan password dapat diatur saat penambahan
    ✓ Terukur: Mudah reset password jika lupa atau perlu pergantian
    ✓ Terintegrasi: Akun siswa terhubung dengan fitur presensi, nilai, perizinan, dll

    Akses Modul Data Siswa

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Siswa

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri), cari "Siswa" di bawah grup "Personil"
    3. Klik Siswa
    4. Anda akan masuk ke halaman daftar siswa

    Direct URL: 

    https://edupoin.sekolah.id/admin/siswas
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Menambahkan Siswa Baru

    Langkah 1: Masuk ke Halaman Daftar Siswa

    Ikuti petunjuk di bagian Akses Modul Data Siswa

    Langkah 2: Klik Tombol "Tambah Siswa"

    Di halaman daftar siswa, Anda akan melihat tombol berwarna biru "+ Tambah Siswa" di sudut kanan atas.

    ┌─────────────────────────────────────────────┐
│  [← Kembali]     Daftar Siswa               │
├─────────────────────────────────────────────┤
│                        [+ Tambah Siswa] ▼   │
│                                             │
│ Tabel daftar siswa...                       │
└─────────────────────────────────────────────┘

    Klik tombol tersebut.

    Langkah 3: Isi Form Data Identitas

    Form akan terbuka dengan beberapa bagian yang dapat dilipat (collapsible). Mulai dari section "Data Identitas":

    Data Identitas (Wajib diisi)

    Field Keterangan Contoh
    NISN Nomor Induk Siswa Nasional 0123456789
    NIS Nomor Induk Siswa (lokal sekolah) 001
    Nama Lengkap Nama lengkap siswa Sumbawa Pratama
    Tanggal Lahir Pilih tanggal dari date picker 15 Januari 2010
    Jenis Kelamin Pilih: Laki-laki atau Perempuan Laki-laki
    Tahun Masuk Tahun siswa mulai di sekolah 2022

    Contoh: 

    NISN: 0123456789
NIS: 001
Nama Lengkap: Sumbawa Pratama
Tanggal Lahir: 15 Januari 2010
Jenis Kelamin: Laki-laki
Tahun Masuk: 2022

    Langkah 4: Isi Form Data Akademik

    Klik atau expand section "Data Akademik":

    Field Keterangan Catatan
    Kelas Pilih kelas tempat siswa ditempatkan Opsional, dapat diubah nanti
    Nomor Urut Nomor urut siswa di kelas Opsional

    Contoh: 

    Kelas: X-A
Nomor Urut: 15

    Langkah 5: Isi Form Kontak & Alamat

    Expand section "Kontak & Alamat":

    Field Keterangan Catatan
    Alamat Alamat lengkap tempat tinggal siswa Opsional

    Contoh: 

    Alamat: Jl. Merdeka No. 42, Kota Mataram, NTB 83115

    Langkah 6: Isi Form Akun Sistem ⭐ (Penting!)

    INI ADALAH BAGIAN BARU — Setiap siswa baru akan mendapat akun login. Expand section "Akun Sistem":

    Field Keterangan Default Catatan
    Username Username untuk login siswa NISN Jika kosong, akan otomatis = NISN. Harus unik.
    Password Password untuk login siswa Username Jika kosong, akan otomatis = Username. Minimum 8 karakter jika diisi manual.
    Email Email siswa (opsional) - Dapat diisi nanti, tidak wajib

    Langkah 7: Simpan Data

    Setelah semua field diisi:

    1. Scroll ke bawah
    2. Klik tombol "Simpan" (berwarna hijau)

    Apa yang terjadi otomatis: - ✅ Data siswa disimpan ke database - ✅ User account dibuat dengan username dan password yang Anda tentukan - ✅ Role "Siswa" otomatis di-assign - ✅ Notifikasi sukses muncul dengan menampilkan username & password yang baru dibuat

    ✅ Siswa berhasil ditambahkan
Username: 0123456789 | Password: 0123456789

    ⚠️ Penting!

    • Password default = username jika Anda tidak mengisi field password
    • Catat/screenshot password untuk referensi jika perlu diberikan ke siswa/wali
    • Username harus unik — sistem akan menolak jika ada duplikasi
    • NISN biasanya unik — gunakan NISN sebagai username untuk kemudahan

    Panduan: Mengubah Data Siswa

    Langkah 1: Buka Halaman Daftar Siswa

    Masuk ke modul Siswa (lihat Akses Modul Data Siswa)

    Langkah 2: Cari Siswa yang Ingin Diubah

    Di halaman daftar: - Scroll untuk melihat lebih banyak siswa - Search: Ketik nama atau NISN di kolom pencarian untuk menemukan siswa cepat - Sort: Klik nama kolom untuk mengurutkan (nama, NISN, kelas, dll)

    Langkah 3: Klik Nama Siswa untuk Edit

    Klik pada nama siswa atau tombol "✏️ Edit" (jika ada) di baris siswa.

    Halaman edit akan terbuka dengan form yang sama saat penambahan.

    Langkah 4: Ubah Data yang Diperlukan

    Anda dapat mengubah: - ✅ Nama lengkap - ✅ Tanggal lahir, jenis kelamin - ✅ Kelas, nomor urut - ✅ Alamat - ✅ Email siswa - ✅ Username user account - ✅ Password user account (opsional)

    Catatan: - Field NISN dan NIS tidak dapat diubah (untuk integritas data) - Jika mengubah username, pastikan tidak ada duplikasi

    Langkah 5: Simpan Perubahan

    Scroll ke bawah dan klik "Simpan".

    Notifikasi sukses akan muncul jika perubahan berhasil disimpan.

    Panduan: Reset Password Siswa

    Situasi Ketika Reset Password Diperlukan

    • Siswa lupa password
    • Admin ingin mereset ke default untuk keamanan
    • Siswa baru perlu password baru setelah menerima akun

    Langkah 1-3: Buka Halaman Edit Siswa

    Ikuti langkah 1-3 dari Panduan: Mengubah Data Siswa

    Langkah 4: Klik Tombol "Reset Password"

    Di bagian atas halaman edit (header), Anda akan melihat beberapa tombol:

    [← Kembali]     Sumbawa Pratama
[🔑 Reset Password]  [🗑️ Hapus]

    Klik tombol "🔑 Reset Password" (berwarna kuning/warning).

    Langkah 5: Konfirmasi Reset

    Modal dialog akan muncul dengan pesan:

    ┌─────────────────────────────────────────────────────┐
│ Reset Password ke Default                          │
├─────────────────────────────────────────────────────┤
│                                                     │
│ Password akan direset ke default (sama dengan      │
│ username). Pastikan siswa sudah siap menerima      │
│ password baru.                                      │
│                                                     │
│        [Batal]  [Reset]                           │
└─────────────────────────────────────────────────────┘

    Klik "Reset" untuk mengonfirmasi.

    Langkah 6: Catat Password Baru

    Notifikasi sukses akan muncul:

    ✅ Password berhasil direset
Password kini: 0123456789

    Catat/screenshot password baru untuk referensi.

    ✨ Apa yang Terjadi Setelah Reset

    • Password siswa direset ke username-nya
    • Siswa dapat login dengan username dan password baru
    • Disarankan siswa mengubah password setelah login pertama

    Panduan: Menghapus Data Siswa

    ⚠️ Perhatian Penting!

    • Penghapusan bersifat permanen — data tidak dapat dipulihkan
    • User account juga dihapus — siswa tidak dapat login lagi
    • Data akademik terkait (presensi, nilai, dll) tetap tersimpan untuk audit trail
    • Gunakan dengan hati-hati — hanya untuk data siswa yang salah atau duplikasi

    Langkah 1-3: Buka Halaman Edit Siswa

    Ikuti langkah 1-3 dari Panduan: Mengubah Data Siswa

    Langkah 4: Klik Tombol "Hapus"

    Di bagian atas halaman edit, klik tombol "🗑️ Hapus" (berwarna merah).

    Langkah 5: Konfirmasi Penghapusan

    Modal dialog akan muncul:

    ┌─────────────────────────────────────────────────────┐
│ Hapus Data Siswa?                                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│ Tindakan ini tidak dapat dibatalkan. Data siswa     │
│ dan user account akan dihapus permanen.             │
│                                                     │
│        [Batal]  [Hapus]                           │
└─────────────────────────────────────────────────────┘

    Klik "Hapus" untuk konfirmasi final.

    Langkah 6: Proses Selesai

    Data siswa berhasil dihapus dan Anda akan kembali ke halaman daftar siswa.

    Manajemen Pengguna (User) Sistem

    📍 Perbedaan: Menu "Siswa" vs Menu "Pengguna"

    Sistem memiliki dua halaman berbeda:

    Menu Lokasi Untuk Keterangan
    Siswa Admin → Personil → Siswa Manajemen data siswa & akun mereka Untuk TU mengelola siswa + akun otomatis
    Pengguna Admin → Sistem & Pengguna → Pengguna Manajemen user non-siswa (Guru, Admin, dll) Untuk TU mengelola user lain (Guru, Wali Kelas, BK, Kesiswaan, dll)

    🛡️ Perlindungan: User Siswa Tidak Bisa Diubah via Menu Pengguna

    Untuk mencegah human error, sistem dirancang dengan aturan ketat:

    • ✅ User siswa HANYA dapat dikelola melalui menu "Siswa"
    • ✅ Menu "Pengguna" tidak akan menampilkan user siswa
    • ✅ Tidak ada opsi untuk assign role "Siswa" di menu "Pengguna"
    • ✅ Role "Siswa" otomatis saat siswa ditambahkan via menu "Siswa"

    Alasan: Untuk memastikan setiap siswa hanya punya role "Siswa" dan tidak bisa salah di-assign role lain (Guru, Admin, dll).

    📋 Mengelola User Guru & Staf

    Jika ingin mengelola user guru, wali kelas, atau staf lain:

    1. Masuk ke Admin Panel → Sistem & Pengguna → Pengguna
    2. Di sini hanya akan muncul user non-siswa
    3. Anda dapat tambah, edit, atau hapus user guru/staf

    Catatan: Role "Siswa" tidak akan muncul di opsi role di halaman "Pengguna" untuk mencegah kesalahan.

    Tips & Best Practice

    📌 Saat Menambah Siswa Baru

    1. Gunakan NISN sebagai Username
    2. NISN biasanya unik dan mudah diingat

    3. Contoh: Username 0123456789 (dari NISN)

    4. Password Default = Username

    5. Untuk kemudahan, biarkan password otomatis = username

    6. Siswa dapat mengubah password sendiri setelah login pertama

    7. Catat Credentials untuk Referensi

    8. Screenshot atau catat username & password yang ditampilkan setelah simpan

    9. Berguna jika perlu memberikan ke siswa/wali atau troubleshooting

    10. Isi Kelas & Alamat dengan Teliti

    11. Informasi ini digunakan untuk fitur presensi, nilai, dan notifikasi

    12. Alamat salah dapat menyebabkan masalah komunikasi dengan wali

    13. Cek Duplikasi NISN/NIS Sebelum Input

    14. Gunakan fitur pencarian untuk pastikan tidak ada duplikasi
    15. Duplikasi data dapat menyebabkan kesalahan perhitungan nilai

    🔐 Saat Reset Password

    1. Reset hanya jika diperlukan

    2. Jangan reset tanpa alasan untuk keamanan

    3. Komunikasi dengan Siswa

    4. Jika reset karena siswa lupa, beri tahu password baru kepada siswa/wali

    5. Disarankan siswa ubah password setelah login pertama

    6. Audit Trail

    7. Setiap reset password tercatat untuk keperluan audit

    📊 Saat Membuka Halaman Daftar Siswa

    1. Gunakan Pencarian untuk Efisiensi
    2. Ketik NISN atau nama jika ingin cari siswa spesifik

    3. Pencarian lebih cepat daripada scroll manual

    4. Gunakan Filter & Sort

    5. Sort berdasarkan kelas, NISN, atau nama untuk melihat data terstruktur

    6. Filter dapat membantu membuat laporan

    7. Export Data (Jika Tersedia)

    8. Beberapa sistem memungkinkan export ke Excel/CSV
    9. Berguna untuk laporan atau backup data

    Pertanyaan Umum (FAQ)

    ❓ P: Apa bedanya tambah siswa di menu "Siswa" vs tambah user di menu "Pengguna"?

    J: Menu "Siswa" adalah tempat SATU-SATUNYA untuk menambah siswa. Saat Anda tambah siswa di sini, user account otomatis dibuat dengan role "Siswa". Menu "Pengguna" adalah untuk user lain (Guru, Admin, Kesiswaan, dll), bukan untuk siswa. Sistem dirancang ini untuk mencegah human error — siswa tidak akan kebetulan di-assign role yang salah.

    ❓ P: Bisakah saya ubah username siswa setelah ditambahkan?

    J: Ya, bisa. Saat edit siswa, Anda dapat mengubah username di field "Username" di section "Akun Sistem". Pastikan username baru tidak duplikasi dengan siswa lain.

    ❓ P: Jika saya ubah password siswa, apakah yang lama masih bisa dipakai?

    J: Tidak. Password lama akan langsung di-replace dengan password baru. Siswa harus login dengan password baru. Pastikan Anda catat atau beri tahu password baru kepada siswa.

    ❓ P: Bagaimana jika siswa lupa password?

    J: Gunakan fitur Reset Password di halaman edit siswa. Password akan direset ke default (username). Catat password baru dan beri tahu kepada siswa. Disarankan siswa mengubah password setelah login pertama.

    ❓ P: Apakah saya bisa membuat username manual, bukan dari NISN?

    J: Ya, bisa. Di form "Akun Sistem" saat tambah siswa, isi field "Username" dengan nilai custom. Pastikan tidak duplikasi. Jika Anda kosongkan, sistem otomatis gunakan NISN.

    ❓ P: Jika saya hapus siswa, apakah data presensi dan nilai hilang juga?

    J: Tidak. Data presensi dan nilai siswa tetap tersimpan untuk audit trail dan laporan. Yang dihapus adalah data siswa dan user account-nya. Fitur ini aman untuk integritas data akademik.

    ❓ P: Bisakah dua siswa punya username yang sama?

    J: Tidak. Sistem akan menolak jika ada duplikasi username. Pastikan setiap siswa punya username unik. Gunakan NISN jika ingin auto-generate, karena NISN seharusnya unik per siswa nasional.

    ❓ P: Dimana saya bisa lihat audit trail perubahan data siswa?

    J: Detail audit trail tergantung konfigurasi sistem. Biasanya tercatat di AuditTrail atau Activity Log di bagian admin. Hubungi admin sistem untuk detail lebih lanjut.

    ❓ P: Password minimum berapa karakter?

    J: Password minimum 8 karakter jika Anda input manual. Jika Anda kosongkan, password otomatis = username.

    ❓ P: Bisakah saya reset password multiple siswa sekaligus (batch)?

    J: Fitur batch reset belum tersedia di versi ini. Anda harus reset satu per satu melalui halaman edit siswa. Fitur ini dapat ditambahkan di versi mendatang jika diperlukan.

    1. Hubungi Admin Sistem — untuk teknis dan akses
    2. Baca dokumentasi lain di folder /docs untuk fitur terkait
    3. Cek log aplikasi — jika ada error, biasanya ada pesan detail
