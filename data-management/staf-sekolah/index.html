    Pengenalan Singkat

    Modul Staf Sekolah adalah fitur di EduPoin untuk mengelola data staf (tendik) di sekolah seperti TU, Admin, Satpam, Kebersihan, dan lainnya.

    🎯 Fitur Utama

    Fitur Deskripsi
    Tambah Staf Menambahkan staf baru dengan data administratif
    Conditional User Creation User account hanya dibuat untuk jabatan tertentu (TU & Admin)
    Auto Role Assignment Role otomatis di-assign sesuai jabatan
    Flexible Jabatan Mendukung berbagai jabatan: TU, Admin, Satpam, Kebersihan, Lainnya
    Edit Data Staf Mengubah data, jabatan, dan akun staf
    Account Management Otomatis buat/hapus akun saat jabatan berubah

    ✨ Konsep Kondisional Akun

    Tidak semua staf memerlukan akun login ke sistem. Keputusan sebagai berikut:

    Jabatan Butuh Akun? Role Akses
    TU ✅ Ya TU Manage master data
    Admin ✅ Ya Admin System administration
    Satpam ❌ Tidak - Data record administratif saja
    Kebersihan ❌ Tidak - Data record administratif saja
    Lainnya ❌ Tidak - Data record administratif saja

    💡 Manfaat Pendekatan Ini: - ✓ Keamanan: Hanya staf yang perlu akses yang mendapat login - ✓ Efisien: Tidak ada akun tidak terpakai di sistem - ✓ Fleksibel: Jabatan dapat diubah kapan saja, akun akan otomatis di-sinkron - ✓ Terukur: Audit trail akses lebih jelas per jabatan

    Akses Modul Staf Sekolah

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Staf Sekolah

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri), cari "Staf Sekolah" di bawah grup "Personil"
    3. Klik Staf Sekolah
    4. Anda akan masuk ke halaman daftar staf

    Direct URL: 

    https://edupoin.sekolah.id/admin/tendiks
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Menambahkan Staf Baru

    Langkah 1: Masuk ke Halaman Daftar Staf

    Ikuti petunjuk di bagian Akses Modul Staf Sekolah

    Langkah 2: Klik Tombol "Tambah Staf"

    Di halaman daftar staf, Anda akan melihat tombol berwarna biru "+ Tambah Staf" di sudut kanan atas.

    ┌─────────────────────────────────────────────────────┐
│  [← Kembali]     Daftar Staf Sekolah                │
├─────────────────────────────────────────────────────┤
│                        [+ Tambah Staf] ▼             │
│                                                     │
│ Tabel daftar staf...                                │
└─────────────────────────────────────────────────────┘

    Klik tombol tersebut.

    Langkah 3: Isi Form Identitas Staf

    Form akan terbuka dengan beberapa bagian yang dapat dilipat (collapsible). Mulai dari section "Identitas Staf Sekolah":

    Identitas Staf Sekolah (Wajib diisi)

    Field Keterangan Contoh Aturan
    NIK Nomor Induk Kependudukan / ID Staf 197803141998021001 Wajib, harus unik (tidak boleh duplikat)
    Nama Lengkap Nama lengkap staf Pak Ahmad Santoso Wajib, maksimal 255 karakter

    Contoh: 

    NIK: 197803141998021001
Nama Lengkap: Pak Ahmad Santoso

    Langkah 4: Isi Form Posisi & Kontak

    Klik atau expand section "Posisi & Kontak":

    Field Keterangan Pilihan Wajib
    Jabatan Jabatan staf di sekolah • TU
    • Admin
    • Satpam
    • Kebersihan
    • Lainnya    		 Ya
    Telepon Nomor telepon staf (opsional) Contoh: 087777123456 Tidak

    📌 PENTING - Perhatikan Pilihan Jabatan: - TU: Staf akan mendapat akun login (role: TU) untuk manage master data - Admin: Staf akan mendapat akun login (role: Admin) untuk sistem administratif - Satpam: Staf akan dicatat di database, TIDAK mendapat akun login - Kebersihan: Staf akan dicatat di database, TIDAK mendapat akun login - Lainnya: Staf akan dicatat di database, TIDAK mendapat akun login

    Contoh: 

    Jabatan: TU
Telepon: 087777123456

    Langkah 5: Isi Form Alamat

    Expand section "Alamat & Akun" dan mulai dari bagian alamat:

    Field Keterangan Contoh Wajib
    Alamat Alamat tempat tinggal staf Jl. Mawar No. 5, Kota Mataram Tidak

    Contoh: 

    Alamat: Jl. Mawar No. 5, Kota Mataram, NTB 83115

    Langkah 6: Isi Form Akun Pengguna ⭐ (Hanya jika Jabatan = TU atau Admin)

    INI ADALAH BAGIAN KONDISIONAL — Form ini hanya akan muncul jika jabatan yang dipilih adalah TU atau Admin.

    Pada bagian yang sama "Alamat & Akun", Anda akan melihat section "Akun Pengguna" yang dapat dilipat:

    Field Keterangan Default Catatan
    Username Username untuk login staf NIK Jika kosong, akan otomatis = NIK. Harus unik.
    Password Password untuk login staf NIK Jika kosong, akan otomatis = NIK. Staf bisa ubah saat first login.
    Email Email staf (opsional) - Dapat diisi nanti, tidak wajib

    💡 Rekomendasi: - Kosongkan username & password untuk menggunakan NIK sebagai keduanya (simple & mudah diingat) - Atau isikan username custom jika ingin berbeda dari NIK - Password dapat direset kapan saja oleh admin

    Langkah 7: Simpan Data

    Setelah semua field wajib diisi:

    1. Scroll ke bawah
    2. Klik tombol "Simpan" (berwarna hijau)

    Apa yang terjadi otomatis (Jika Jabatan = TU/Admin): - ✅ Data staf disimpan ke database - ✅ User account dibuat dengan username dan password yang Anda tentukan (atau NIK jika kosong) - ✅ Role "TU" atau "Admin" otomatis di-assign sesuai jabatan - ✅ Notifikasi muncul dengan pesan sukses dan menampilkan username/password

    Apa yang terjadi otomatis (Jika Jabatan = Satpam/Kebersihan/Lainnya): - ✅ Data staf disimpan ke database - ✅ TIDAK ada user account yang dibuat - ✅ Notifikasi muncul: "Staf berhasil ditambahkan (tanpa akun login)"

    Panduan: Mengubah Data Staf

    Skenario 1: Mengubah Data Identitas atau Kontak

    1. Buka halaman Daftar Staf Sekolah
    2. Cari staf yang ingin diubah di tabel
    3. Klik nama staf atau ikon "Edit" (pensil)
    4. Ubah data sesuai kebutuhan
    5. Klik "Simpan Perubahan"

    Skenario 2: Mengubah Jabatan dari Satpam menjadi TU

    Sebelumnya: Staf Satpam tidak memiliki akun login Sesudahnya: Staf akan mendapat akun login dengan role "TU"

    Langkah: 1. Buka halaman edit staf 2. Di section "Posisi & Kontak", ubah Jabatan dari "Satpam" menjadi "TU" 3. Section "Akun Pengguna" akan muncul 4. Isi form akun (atau kosongkan untuk auto-generate dari NIK) 5. Klik "Simpan Perubahan" 6. ✅ User account otomatis dibuat dengan role "TU"

    Skenario 3: Mengubah Jabatan dari TU menjadi Satpam

    Sebelumnya: Staf TU memiliki akun login dengan role "TU" Sesudahnya: Akun login akan dihapus, staf hanya menjadi data record

    Langkah: 1. Buka halaman edit staf 2. Di section "Posisi & Kontak", ubah Jabatan dari "TU" menjadi "Satpam" 3. Section "Akun Pengguna" akan hilang 4. Klik "Simpan Perubahan" 5. ✅ User account otomatis dihapus/detached

    Skenario 4: Mengubah Jabatan dari TU menjadi Admin

    Sebelumnya: Staf TU dengan role "TU" Sesudahnya: Role berubah menjadi "Admin"

    Langkah: 1. Buka halaman edit staf 2. Di section "Posisi & Kontak", ubah Jabatan dari "TU" menjadi "Admin" 3. Section "Akun Pengguna" tetap muncul 4. Klik "Simpan Perubahan" 5. ✅ Role staf otomatis berubah dari "TU" menjadi "Admin"

    Keputusan Jabatan & Akun Login

    📊 Matrix Keputusan

    Jabatan Deskripsi Akun? Role Tanggung Jawab
    TU Tata Usaha ✅ Ya TU Kelola master data (guru, siswa, kelas, mapel, dll)
    Admin Admin Sistem ✅ Ya Admin Manajemen user, backup, konfigurasi sistem
    Satpam Petugas Keamanan ❌ Tidak - Keamanan lingkungan sekolah (tidak perlu akses sistem)
    Kebersihan Petugas Kebersihan ❌ Tidak - Kebersihan lingkungan sekolah (tidak perlu akses sistem)
    Lainnya Posisi lainnya ❌ Tidak - Tergantung kebutuhan, konsultasi dengan kepala sekolah

    🤔 Cara Memutuskan Jabatan Staf

    Pertanyaan untuk Menentukan:

    1. Apakah staf perlu login ke sistem EduPoin?
    2. ✅ Ya → Pilih TU atau Admin

    3. ❌ Tidak → Pilih Satpam/Kebersihan/Lainnya

    4. Apakah staf akan mengelola data master (guru, siswa, kelas)?

    5. ✅ Ya → Pilih TU

    6. ❌ Tidak → Pertanyaan 3

    7. Apakah staf perlu akses administratif penuh (user management, backup)?

    8. ✅ Ya → Pilih Admin
    9. ❌ Tidak → Pilih Satpam/Kebersihan/Lainnya

    Tips & Best Practice

    🎯 Keamanan & Password

    Praktik Alasan
    Gunakan NIK sebagai password default Mudah diingat, tapi sebaiknya staf ubah saat first login
    Jangan share password via email Beritahu langsung atau cetak saat create
    Reset password secara berkala Untuk keamanan akun jangka panjang

    📝 Penamaan & Konsistensi

    Praktik Contoh
    Gunakan nama lengkap sesuai KTP ✓ Pak Ahmad Santoso
    ✗ Ahmad
    NIK sesuai dokumen resmi Hindari typo atau kesalahan input
    Jabatan dipilih dari dropdown Jangan custom entry, gunakan pilihan yang sudah ada

    🔄 Workflow Rekomendasi

    Saat Penambahan Staf Baru (TU/Admin):

    1. TU menerima dokumen staf (SK, identitas, dll)
    2. TU tentukan jabatan staf (TU atau Admin?)
    3. Jika jabatan = TU/Admin: Input data di EduPoin
    4. Sistem auto-generate username & password (= NIK)
    5. TU catat kredensial & informasikan ke staf
    6. Staf login & ubah password di form profil (first login)
    7. Staf siap menggunakan sistem

    Saat Penambahan Staf Lainnya (Satpam/Kebersihan):

    1. TU menerima dokumen staf
    2. TU pilih jabatan sesuai (Satpam/Kebersihan/Lainnya)
    3. Input data di EduPoin (cukup identitas, posisi, alamat)
    4. Simpan → sistem TIDAK membuat akun
    5. Data staf tercatat di sistem untuk keperluan administratif

    Pertanyaan Umum (FAQ)

    ❓ Bagaimana cara reset password staf yang lupa?

    Jawab: Admin dapat mengakses menu "User Management" untuk reset password staf (TU/Admin). Password akan direset ke nilai default (NIK) atau value lain sesuai kebijakan sekolah.

    ❓ Bisa tidak staf Satpam mendapat akun login?

    Jawab: Sistem EduPoin dirancang bahwa Satpam tidak perlu akun login. Namun jika ada kebutuhan khusus (misalnya Satpam perlu input data keamanan), ubah jabatan ke "Lainnya" dan konsultasi dengan kepala IT untuk custom role.

    ❓ Apa bedanya staf TU dengan staf Admin?

    Jawab: - TU: Role "TU" → dapat kelola master data (guru, siswa, kelas, mapel, penugasan guru, dll) - Admin: Role "Admin" → akses administratif penuh termasuk user management, backup, konfigurasi sistem

    ❓ Bisakah satu staf memiliki dua jabatan sekaligus?

    Jawab: Tidak. Satu staf = satu jabatan. Jika staf perlu pindah jabatan, edit halaman staf dan ubah jabatan, maka role otomatis akan di-sync.

    ❓ Apa yang terjadi jika saya ubah jabatan TU menjadi Satpam?

    Jawab: Akun login staf akan otomatis dihapus/detached dari sistem. Staf tidak bisa login lagi, tapi data staf tetap tersimpan di database untuk keperluan administratif. ⚠️ HATI-HATI: Sebelum ubah, pastikan tidak ada data penting yang belum diselesaikan oleh staf tersebut.

    ❓ Bagaimana cara menghapus akun staf?

    Jawab: Klik tombol "Hapus" (icon trash) di halaman edit staf. Data staf dan akunnya (jika ada) akan dihapus dari sistem. ⚠️ HATI-HATI: Tindakan ini tidak bisa diunduh. Gunakan hanya jika data entry salah atau staf resign.

    ❓ Apakah staf bisa login dari mana saja?

    Jawab: Ya. Staf dapat login dari laptop, tablet, atau smartphone asalkan ada koneksi internet ke URL sekolah. Direkomendasikan untuk keamanan, batasi akses dari IP sekolah saja (setting server).

    ❓ Bagaimana jika ada staf baru dengan jabatan yang belum ada di dropdown?

    Jawab: Pilih "Lainnya". Jika ada kebutuhan jabatan baru secara regular, hubungi developer untuk menambahkan ke dropdown jabatan staf.
