    Pengenalan Singkat

    Modul Staf Sekolah adalah fitur di EduPoin untuk mengelola biodata staf administratif (tendik) di sekolah seperti TU, Admin, Satpam, Kebersihan, dan lainnya. Modul ini terpisah dari manajemen akun login — artinya Anda hanya mengelola informasi pribadi, jabatan, dan status staf di sini.

    🎯 Fitur Utama

    Fitur Deskripsi
    Tambah Staf Menambahkan staf baru dengan data administratif
    Edit Data Staf Mengubah data identitas, jabatan, dan status staf
    Hapus Data Staf Menghapus data staf (akun terpisah, tidak terhapus di sini)
    Lihat Daftar Staf Melihat semua staf terdaftar di sekolah
    Search & Filter Mencari staf berdasarkan nama, jabatan, status, dll

    ✨ Manfaat Pemisahan Biodata & Akun

    ✓ Fleksibel: Staf bisa didaftarkan biodata dulu, akun dibuat kemudian
    ✓ Aman: Data staf tidak akan hilang jika akun dihapus
    ✓ Terukur: Admin mengontrol kapan staf mendapat akses login
    ✓ Efisien: Mudah mengelola staf tidak sistematis dan staf berbasis akun
    ✓ Terstruktur: Alur jelas — biodata dulu (Personil → Tendik), akun kemudian (Sistem & Pengguna → Akun Internal)

    Workflow: Biodata & Akun Terpisah

    Alur Pembuatan Akun Staf

    1️⃣ BIODATA STAF (Menu: Personil → Tendik)
   ├─ Tambah nama, jabatan, status, dll
   └─ Staf dapat mulai dikelola di sistem

2️⃣ AKUN STAF (Menu: Sistem & Pengguna → Akun Internal) — HANYA UNTUK TERTENTU
   ├─ Pilih staf yang MEMBUTUHKAN akun (TU, Admin, Kesiswaan, BK, dll)
   ├─ Set username & password
   ├─ Set role sesuai jabatan
   └─ Staf dapat login ke sistem

3️⃣ AKSES FITUR (Staf dapat menggunakan aplikasi)
   ├─ TU: Master data, Import siswa, Report
   ├─ Admin: Sistem & keamanan
   ├─ Kesiswaan: Manajemen perizinan
   └─ BK: Konseling & monitoring siswa

    ⚠️ Penting!

    • Modul ini (Staf Sekolah) = Hanya untuk biodata
    • Untuk membuat akun staf, masuk ke menu "Sistem & Pengguna → Akun Internal"
    • Tidak semua staf perlu akun — hanya yang memerlukan akses sistem (TU, Admin, Kesiswaan, BK, dll)
    • Staf tanpa akun (Satpam, Kebersihan, dll) tetap terdaftar biodata untuk keperluan administratif
    • Lihat panduan lengkap di: AKUN_INTERNAL_USER_GUIDE.md

    Akses Modul Staf Sekolah

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Staf Sekolah

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri), cari "Staf Sekolah" di bawah grup "Personil"
    3. Klik Staf Sekolah
    4. Anda akan masuk ke halaman daftar staf

    Direct URL: 

    https://edupoin.sekolah.id/admin/tendiks
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Menambahkan Staf Baru

    Langkah 1: Masuk ke Halaman Daftar Staf

    Ikuti petunjuk di bagian Akses Modul Staf Sekolah

    Langkah 2: Klik Tombol "Tambah Staf"

    Di halaman daftar staf, Anda akan melihat tombol berwarna biru "+ Tambah Staf" di sudut kanan atas.

    ┌─────────────────────────────────────────────────────┐
│  [← Kembali]     Daftar Staf Sekolah                │
├─────────────────────────────────────────────────────┤
│                        [+ Tambah Staf] ▼             │
│                                                     │
│ Tabel daftar staf...                                │
└─────────────────────────────────────────────────────┘

    Klik tombol tersebut.

    Langkah 3: Isi Form Identitas Staf

    Form akan terbuka dengan beberapa bagian yang dapat dilipat (collapsible). Mulai dari section "Identitas Staf Sekolah":

    Identitas Staf Sekolah (Wajib diisi)

    Field Keterangan Contoh Aturan
    NIK Nomor Induk Kependudukan / ID Staf 197803141998021001 Wajib, harus unik (tidak boleh duplikat)
    Nama Lengkap Nama lengkap staf Pak Ahmad Santoso Wajib, maksimal 255 karakter

    Contoh: 

    NIK: 197803141998021001
Nama Lengkap: Pak Ahmad Santoso

    Langkah 4: Isi Form Posisi & Kontak

    Klik atau expand section "Posisi & Kontak":

    Field Keterangan Pilihan Wajib
    Jabatan Jabatan staf di sekolah • TU
    • Admin
    • Satpam
    • Kebersihan
    • Lainnya    		 Ya
    Telepon Nomor telepon staf (opsional) Contoh: 087777123456 Tidak

    Contoh: 

    Jabatan: TU
Telepon: 087777123456

    Langkah 5: Isi Form Alamat

    Expand section "Alamat":

    Field Keterangan Contoh Wajib
    Alamat Alamat tempat tinggal staf Jl. Mawar No. 5, Kota Mataram Tidak

    Contoh: 

    Alamat: Jl. Mawar No. 5, Kota Mataram, NTB 83115

    Langkah 6: Simpan Data

    Setelah semua field wajib diisi:

    1. Scroll ke bawah
    2. Klik tombol "Simpan" (berwarna hijau)

    Apa yang terjadi otomatis: - ✅ Data staf disimpan ke database - ✅ Staf tersedia untuk pembuatan akun di modul "Akun Internal" nanti (jika diperlukan) - ✅ Notifikasi sukses muncul

    ✅ Staf berhasil ditambahkan

    📝 Contoh Pengisian Lengkap

    ┌──────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────┤

│ Nama Lengkap:        Pak Ahmad Santoso               │
├──────────────────────────────────────────────────────┤
│ POSISI & KONTAK                                      │
├──────────────────────────────────────────────────────┤
│ Jabatan:             TU                              │
│ Telepon:             087777123456                    │
├──────────────────────────────────────────────────────┤
│ ALAMAT                                               │
├──────────────────────────────────────────────────────┤
│ Alamat:              Jl. Mawar No. 5, Kota Mataram  │
└──────────────────────────────────────────────────────┘

    ⚠️ Catatan

    • Modul ini hanya untuk biodata — tidak ada field username/password
    • Untuk membuat akun staf (jika diperlukan), masuk ke menu "Sistem & Pengguna → Akun Internal"
    • Di sana Anda akan memilih staf dan set username + password + role sesuai kebutuhan
    • Tidak semua staf perlu akun — hanya yang memerlukan akses sistem (TU, Admin, Kesiswaan, BK, dll)
    • Lihat: AKUN_INTERNAL_USER_GUIDE.md

    Panduan: Mengubah Data Staf

    Skenario 1: Mengubah Data Identitas atau Kontak

    1. Buka halaman Daftar Staf Sekolah
    2. Cari staf yang ingin diubah di tabel
    3. Klik nama staf atau ikon "Edit" (pensil)
    4. Ubah data sesuai kebutuhan
    5. Klik "Simpan Perubahan"

    Skenario 2: Menghapus Data Staf

    Untuk menghapus data staf: 1. Buka halaman Daftar Staf Sekolah 2. Cari staf yang ingin dihapus 3. Klik ikon "Hapus" (tempat sampah) 4. Konfirmasi penghapusan 5. ✅ Data staf dihapus

    ⚠️ Penting tentang Akun saat Menghapus Staf

    Jika staf memiliki akun login: 1. Hapus akun dulu di menu "Sistem & Pengguna → Akun Internal" 2. Kemudian hapus data staf di modul ini

    Ini desain untuk mencegah kecelakaan penghapusan data.

    Tips & Best Practice

    📌 Saat Menambah Staf Baru

    1. Isi Data Dengan Teliti
    2. Pastikan NIK benar (tidak boleh duplikasi)
    3. Cek nama lengkap sesuai identitas resmi staf

    4. Pilih jabatan yang sesuai

    5. Cek Duplikasi Sebelum Simpan

    6. Gunakan fitur pencarian untuk pastikan tidak ada duplikasi NIK

    7. Duplikasi data dapat menyebabkan masalah

    8. Tentukan Jabatan Dengan Tepat

    9. TU: Untuk staf yang mengelola master data
    10. Admin: Untuk staf yang mengelola sistem

    11. Satpam/Kebersihan/Lainnya: Untuk staf yang tidak perlu akun sistem

    12. Akun Dibuat Terpisah Nanti (Jika Diperlukan)

    13. Setelah staf terdaftar biodata, Anda dapat membuat akun di menu "Akun Internal" jika staf memerlukan akses sistem

    14. Lihat panduan: AKUN_INTERNAL_USER_GUIDE.md

    15. Staf Tanpa Akun Tetap Terdaftar

    16. Staf Satpam/Kebersihan tetap terekam untuk keperluan administratif, meski tidak memiliki akun login

    📊 Saat Membuka Halaman Daftar Staf

    1. Gunakan Pencarian untuk Efisiensi
    2. Ketik NIK atau nama jika ingin cari staf spesifik

    3. Pencarian lebih cepat daripada scroll manual

    4. Gunakan Filter & Sort

    5. Sort berdasarkan nama, NIK, jabatan untuk melihat data terstruktur

    6. Filter dapat membantu membuat laporan

    7. Export Data (Jika Tersedia)

    8. Beberapa sistem memungkinkan export ke Excel/CSV
    9. Berguna untuk laporan atau backup data

    Pertanyaan Umum (FAQ)

    ❓ P: Bagaimana cara membuat akun login untuk staf?

    J: Akun login dibuat terpisah di menu "Sistem & Pengguna → Akun Internal" untuk staf yang memerlukan akses sistem. Tidak semua staf perlu akun. Lihat panduan lengkap di: AKUN_INTERNAL_USER_GUIDE.md

    ❓ P: Apakah akun staf otomatis dibuat saat saya tambah staf?

    J: Tidak lagi. Sejak update terbaru, akun dibuat terpisah. Alur: 1. Tambah biodata staf di menu "Personil → Tendik" (di sini) 2. Buat akun login di menu "Sistem & Pengguna → Akun Internal" (terpisah) — hanya untuk staf yang memerlukan akses

    Ini memberikan fleksibilitas — tidak semua staf perlu akun.

    ❓ P: Staf mana saja yang perlu akun login?

    J: Biasanya: - ✅ TU — Mengelola master data - ✅ Admin — Mengelola sistem - ✅ Kesiswaan — Kelola data siswa & perizinan - ✅ BK — Bimbingan konseling & monitoring - ❌ Satpam — Data record administratif saja - ❌ Kebersihan — Data record administratif saja

    Jika ada kebutuhan khusus, konsultasi dengan admin/kepala TI.

    ❓ P: Apa bedanya staf TU dengan staf Admin?

    J: - TU: Role "TU" → dapat kelola master data (guru, siswa, kelas, mapel, penugasan guru, dll) - Admin: Role "Admin" → akses administratif penuh termasuk user management, backup, konfigurasi sistem

    ❓ P: Bisakah satu staf memiliki dua jabatan sekaligus?

    J: Tidak. Satu staf = satu jabatan. Jika staf perlu pindah jabatan, edit halaman staf dan ubah jabatan.

    ❓ P: Bisakah saya ubah NIK staf setelah ditambahkan?

    J: Tidak. NIK tidak dapat diubah setelah data staf dibuat (untuk integritas data). Jika ada kesalahan, Anda harus: 1. Hapus data staf yang salah 2. Buat staf baru dengan NIK yang benar

    ❓ P: Jika saya hapus staf, apakah akun loginnya juga terhapus?

    J: Tidak otomatis. Anda harus hapus dua kali (jika staf memiliki akun): 1. Hapus akun login di menu "Sistem & Pengguna → Akun Internal" (terlebih dahulu) 2. Hapus data staf di menu "Personil → Tendik" (tempat ini)

    Ini desain untuk mencegah kecelakaan penghapusan data.

    ❓ P: Apa yang terjadi jika saya ubah jabatan TU menjadi Satpam?

    J: Data staf tetap ada, tapi akun login (jika ada) akan detached dari sistem. Staf tidak bisa login lagi.

    ❓ P: Bagaimana cara reset password staf yang lupa?

    J: Admin dapat mengakses menu "Sistem & Pengguna → Akun Internal", cari akun staf, klik Edit, kemudian ubah password. Staf akan mendapat password baru untuk login.

    ❓ P: Bisakah dua staf punya NIK yang sama?

    J: Tidak. NIK harus unik. Sistem tidak memperbolehkan NIK duplikasi. Jika ada duplikasi, periksa apakah staf tersebut sudah terdaftar.

    ❓ P: Dimana saya bisa lihat audit trail perubahan data staf?

    J: Detail audit trail tergantung konfigurasi sistem. Biasanya tercatat di AuditTrail atau Activity Log di bagian admin. Hubungi admin sistem untuk detail lebih lanjut.

    ❓ P: Apa yang harus saya lakukan sebelum menghapus staf?

    J: Sebelum menghapus staf: 1. Pastikan tidak ada data penting yang masih diperlukan 2. Jika staf memiliki akun, hapus akun login terlebih dahulu (di menu "Akun Internal") 3. Baru kemudian hapus data staf (di menu ini)

    Dokumentasi selesai. Pertanyaan? Hubungi Tim Tata Usaha atau Admin Sistem.
