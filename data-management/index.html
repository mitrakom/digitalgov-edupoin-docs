    📊 Data Management - Manajemen Data Sekolah

    Modul Data Management mengelola semua data master yang diperlukan sistem EduPoin, termasuk data siswa, guru, dan staf sekolah dengan sistem akun terintegrasi.

    🎯 Fitur Utama

    1. Manajemen Siswa

    • Tambah siswa baru dengan akun otomatis
    • Edit data personal & akademik siswa
    • Reset password siswa
    • Hapus data siswa dan akunnya
    • Auto role assignment
    • Perlindungan dari human error

    Akses: Admin Sekolah, Tim Tata Usaha (TU)

    2. Manajemen Guru

    • Tambah guru dengan role auto-assignment
    • Edit data guru & NIP
    • Update posisi & Wali Kelas status
    • Password management (default = NIP)
    • Role sync otomatis
    • Hapus data guru dan akun

    Akses: Admin Sekolah, Tim Tata Usaha (TU)

    3. Manajemen Staf Sekolah

    • Tambah staf dengan berbagai jabatan
    • Conditional user creation (hanya TU & Admin)
    • Auto role management
    • Fleksibel pengubahan jabatan
    • Tracking perubahan jabatan
    • Audit trail lengkap

    Akses: Admin Sekolah, Tim Tata Usaha (TU)

    👥 Entitas Data

    Siswa

    - Nama, NIS, Tanggal Lahir
- Alamat, No. HP
- Nama Orang Tua
- Kelas, Jurusan
- Status Aktif/Non-aktif
- Akun User (auto-generated)

    Guru

    - Nama, NIP, Tanggal Lahir
- Spesialisasi, Mata Pelajaran
- Alamat, No. HP
- Wali Kelas (opsional)
- Status Aktif/Cuti/Resign
- Akun User (auto-generated)
- Role: Guru, Wali Kelas (dynamic)

    Staf Sekolah

    - Nama, NIP/NIY, Tanggal Lahir
- Jabatan: TU, Admin, Satpam, dll
- Departemen
- Alamat, No. HP
- Status Aktif/Resign
- Akun User (conditional)
- Role (tergantung jabatan)

    ✅ Checklist Setup Awal

    Minggu 1: Setup Siswa

    • [ ] Login ke Admin Panel
    • [ ] Navigasi: Personil → Siswa
    • [ ] Buat Kelas (Master Data → Kelas)
    • [ ] Tambah Siswa Baru → Buka Modal → Isi Data → Save
    • [ ] Verifikasi akun user otomatis dibuat
    • [ ] Test login dengan akun siswa (password = tanggal lahir)

    Minggu 2: Setup Guru

    • [ ] Navigasi: Personil → Guru
    • [ ] Buat Mapel (Master Data → Mata Pelajaran)
    • [ ] Tambah Guru Baru → Isi Data → Assign Mata Pelajaran
    • [ ] Verifikasi role "Guru" otomatis di-assign
    • [ ] Test login dengan akun guru (password = NIP)
    • [ ] Jika ada Wali Kelas, update status → role "Wali Kelas" otomatis

    Minggu 3: Setup Staf

    • [ ] Navigasi: Personil → Staf Sekolah
    • [ ] Tambah Staf: TU, Admin, Satpam, dll
    • [ ] Verifikasi akun dibuat hanya untuk TU & Admin
    • [ ] Test login staf TU/Admin
    • [ ] Satpam & staf lain tidak dapat login (by design)

    📊 Validasi & Batasan

    Data Batasan Alasan
    NIS Unique, format: YYYY-001 Identitas siswa unik
    NIP Unique, wajib untuk guru Identitas guru unik
    Tanggal Lahir Wajib (password default) Password default = DDMMYYYY
    Email Optional, unique jika ada Untuk komunikasi
    No. HP Optional, format valid Untuk notifikasi SMS/WA
    Kelas Wajib untuk siswa Untuk jadwal & presensi
    Mata Pelajaran Wajib untuk guru Untuk jadwal mengajar

    🔐 Keamanan Data

    Password Default

    • Siswa: Tanggal Lahir (DDMMYYYY)
    • Contoh: 15 Maret 1990 = 15031990
    • Guru: NIP
    • Contoh: NIP 198503152015101001 = 198503152015101001
    • Staf TU/Admin: Tanggal Lahir (DDMMYYYY)

    Rekomendasi

    1. Ganti password setelah login pertama
    2. Jangan share password default
    3. Reset password jika user lupa
    4. Verifikasi email untuk recovery akun

    📈 Best Practices

    ✅ DO

    • Validasi data sebelum input (cek duplikasi NIS/NIP)
    • Backup data sebelum bulk import
    • Test akun baru sebelum di-broadcast ke user
    • Update data secara berkala (alamat, no. HP)
    • Archive user yang resign/pindah

    ❌ DON'T

    • Jangan hapus data aktif tanpa verifikasi
    • Jangan share akun user (setiap orang punya akun sendiri)
    • Jangan ubah NIS/NIP setelah user aktif
    • Jangan buat duplikasi akun untuk user sama

    🆘 FAQ

    Q: Bagaimana jika siswa lupa password? A: Admin dapat reset password ke default (tanggal lahir) di halaman Edit Siswa.

    Q: Apakah setiap siswa perlu akun email unik? A: Tidak wajib. Email opsional, tapi berguna untuk password recovery.

    Q: Bisa import bulk siswa sekaligus? A: Ya, gunakan fitur Import Excel di menu Siswa (format template tersedia).

    Q: Apa bedanya user role "Guru" vs "Wali Kelas"? A: Guru = bisa input nilai & presensi. Wali Kelas = guru + bisa lihat laporan kelas & manajemen lanjutan.
