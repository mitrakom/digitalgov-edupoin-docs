    🚀 Getting Started - Panduan Cepat EduPoin

    Panduan singkat untuk memulai penggunaan EduPoin sesuai dengan peran Anda di sekolah.

    🔐 Login & Akses Sistem

    Langkah 1: Akses Portal

    Buka browser dan masuk ke portal EduPoin Anda: - Admin Panel: https://sekolah.edupoin.id/admin - App Portal (Guru/Siswa/Wali): https://sekolah.edupoin.id

    Langkah 2: Input Kredensial

    • Username: Nomor Induk Pribadi (NIP/NIS) atau email
    • Password: Default = tanggal lahir format DDMMYYYY
    • Contoh: 15 Maret 1990 → 15031990

    Langkah 3: Dashboard

    Setelah login, Anda akan melihat dashboard sesuai peran.

    👨‍🏫 Quick Start: Guru

    Hari Pertama

    1. Login ke App Portal
    2. Buka Presensi → Lihat daftar siswa kelas Anda hari ini
    3. Input Presensi → Tandai hadir/sakit/izin
    4. Lihat Jadwal → Cek jam mengajar hari ini

    Minggu Pertama

    1. Masuk ke Grading Module (Penilaian → Bank Soal)
    2. Buat Tugas Pertama (Grading → Tugas)
    3. Setup Pembobotan (Grading → Pembobotan)
    4. Upload Soal Ujian (Grading → Bank Soal)

    Bulan Pertama

    • Kelola nilai secara rutin
    • Setup online exam
    • Buat laporan akademik
    • Koordinasi dengan Wali Kelas

    📖 Panduan Detail: Presensi | Grading | Ujian Online

    🎓 Quick Start: Siswa

    Hari Pertama

    1. Login ke App Portal
    2. Lihat Presensi → Cek kehadiran Anda hari ini
    3. Lihat Jadwal → Cek jam pelajaran
    4. Lihat Nilai → Cek nilai Anda

    Minggu Pertama

    1. Lihat Tugas → Kerjakan tugas dari guru
    2. Lihat Ujian → Cek jadwal ujian
    3. Setup Notifikasi → Terima notifikasi perubahan nilai/tugas

    Saat Ujian Online

    1. Masuk Ujian → Lihat detail ujian
    2. Baca Instruksi → Pahami aturan ujian
    3. Kerjakan Soal → Jawab setiap pertanyaan
    4. Verifikasi Jawaban → Tinjau ulang sebelum submit

    📖 Panduan Detail: Ujian Online - Siswa | Presensi

    👤 Quick Start: Wali Siswa / Orang Tua

    Hari Pertama

    1. Login ke App Portal dengan akun yang diberikan sekolah
    2. Lihat Dashboard → Ringkasan akademik anak Anda
    3. Lihat Presensi Anak → Cek kehadiran harian
    4. Lihat Nilai Anak → Cek performa akademik

    Minggu Pertama

    1. Setup Telegram → Aktifkan notifikasi via Telegram
    2. Lihat Perizinan → Cek izin/cuti anak
    3. Lihat Tugas → Monitor tugas anak

    Setiap Bulan

    • Pantau perubahan nilai
    • Lihat laporan akademik
    • Terima notifikasi dari sekolah

    📖 Panduan Detail: Orang Tua | Telegram

    🛡️ Quick Start: Admin Sekolah

    Hari Pertama

    1. Login ke Admin Panel
    2. Lihat Dashboard → Ringkasan operasional sekolah
    3. Buka Personil → Lihat data siswa/guru
    4. Buka Master Data → Lihat jadwal & kelas

    Minggu Pertama

    1. Tambah Siswa Baru (Personil → Siswa)
    2. Tambah Guru Baru (Personil → Guru)
    3. Setup Jadwal Pelajaran (Master Data → Jadwal)
    4. Setup Kelas (Master Data → Kelas)

    Bulan Pertama

    • Monitor presensi sekolah
    • Lihat laporan akademik
    • Setup ujian online
    • Koordinasi dengan guru & wali

    📖 Panduan Detail: Data Siswa | Data Guru | Akhir Semester

    📱 Password Management

    Lupa Password?

    1. Hubungi Admin Sekolah
    2. Admin akan reset password Anda ke default (tanggal lahir)
    3. Login dengan password baru
    4. Ubah password di Settings → Profile

    Ganti Password

    1. Login ke system
    2. Settings → Profile → Change Password
    3. Masukkan password lama
    4. Masukkan password baru
    5. Save

    🔔 Notifikasi & Telegram

    Untuk menerima notifikasi penting:

    1. Buka Settings → Notifications
    2. Aktifkan Telegram
    3. Scan QR Code atau klik link
    4. Konfirmasi di Telegram

    Anda akan menerima notifikasi untuk: - ✅ Presensi terbaru - ✅ Nilai baru - ✅ Tugas baru - ✅ Ujian akan dimulai - ✅ Perizinan disetujui

    🌙 Tema & Preferensi

    Dark Mode

    Klik toggle ☀️ / 🌙 di pojok kanan atas untuk beralih tema.

    Bahasa

    Default: Bahasa Indonesia (ID) Pilihan lain tersedia di Settings.

    Zona Waktu

    Settings → Profile → Timezone (auto-set sesuai lokasi sekolah)

    📖 Panduan Lengkap

    Setelah familiar dengan basic, baca panduan detail:

    Peran Modul Utama Waktu Baca
    Guru Presensi → Grading → Ujian 45 min
    Siswa Ujian Online → Presensi 20 min
    Wali Orang Tua → Telegram 15 min
    Admin Data Siswa → Admin Tools 60 min

    🆘 Troubleshooting Cepat

    Tidak Bisa Login?

    • [ ] Username/password benar?
    • [ ] Akun sudah aktif? (Hubungi Admin)
    • [ ] Browser up-to-date? (Upgrade browser)
    • [ ] Internet lancar? (Check koneksi)

    Halaman Tidak Load?

    • [ ] Refresh browser (Ctrl+R)
    • [ ] Clear cache (Ctrl+Shift+Delete)
    • [ ] Coba browser lain
    • [ ] Hubungi IT Support

    Data Tidak Muncul?

    • [ ] Refresh halaman
    • [ ] Login ulang
    • [ ] Cek tanggal/periode yang dipilih
    • [ ] Hubungi Admin
