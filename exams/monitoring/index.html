    Pengenalan Singkat

    Apa itu Monitoring & Penilaian Essai?

    Monitoring & Penilaian Essai adalah fitur untuk:

    • 📊 Monitor Real-Time — Lihat siapa saja yang sedang mengerjakan ujian, kapan mulai, waktu sisa, nilai real-time
    • ✏️ Nilai Essai — Menilai jawaban essai siswa secara manual dengan score dan feedback
    • 📈 Analisis — Melihat statistik nilai ujian per kelas/siswa
    • 📋 Laporan — Export atau print laporan nilai untuk keperluan rapor/analisis

    Siapa yang Menggunakan?

    Peran Fungsi Akses
    Guru/Guru Wali Membuat ujian → Monitor → Nilai Essai Full (ujian sendiri)
    Wali Kelas Lihat ujian kelasnya → Monitor → Bantu nilai essai Partial (ujian kelas)
    Kepala Sekolah Lihat laporan semua ujian di sekolah View-Only

    Akses Halaman Monitoring

    Dari Menu Daftar Ujian

    1. Buka "Ujian Online" → "Daftar Ujian"
    2. Tabel akan menampilkan semua ujian yang Anda buat/kelola
    3. Cari ujian yang sedang berlangsung atau sudah selesai
    4. Klik tombol "Monitoring" atau "📊"

    Dari Menu Monitoring Langsung (Jika Ada)

    Beberapa sekolah mungkin memiliki shortcut: 1. Di sidebar, cari menu "Monitoring Ujian" atau "Ujian Berlangsung" 2. Sistem akan langsung menampilkan daftar ujian yang sedang active untuk Anda monitor

    Fitur Auto-Refresh

    • Halaman akan auto-refresh setiap 10 detik untuk memperbarui data real-time
    • Anda bisa juga klik tombol "🔄 Refresh Manual" untuk update langsung
    • Ini membantu Anda monitor ujian tanpa perlu reload halaman manual

    Fitur Reset Peserta

    • Pada tabel monitoring tersedia kolom Aksi untuk peserta yang mengalami kendala teknis
    • Guru dapat memilih alasan reset lalu menekan tombol Reset
    • Reset hanya dipakai saat jam ujian masih aktif dan sesi peserta memang perlu dibuka ulang
    • Untuk panduan operasional lengkap, lihat Panduan Penanganan Kasus Khusus

    Lihat Detail Jawaban Siswa

    Akses Halaman Detail

    1. Di tabel monitoring, cari siswa yang ingin Anda lihat detail jawabannya
    2. Klik nama siswa atau tombol "Lihat Detail" / "👁️"
    3. Halaman detail akan terbuka

    Langkah Menilai Essai

    Langkah 1: Baca Jawaban Siswa dengan Teliti

    1. Baca pertanyaan essai (di bagian "PERTANYAAN")
    2. Baca jawaban siswa dengan seksama
    3. Perhatikan:
    4. Apakah jawaban sesuai pertanyaan?
    5. Apakah konsep sudah tepat?
    6. Apakah penjelasan jelas dan terstruktur?
    7. Adakah kekurangan atau kesalahan?

    Langkah 2: Tentukan Nilai

    Nilai essai berkisar dari 0 sampai bobot soal (contoh: 0-30 jika bobot 30).

    Panduan Pemberian Nilai:

    Range Kriteria Contoh
    90-100% (27-30 poin) Sempurna: jawaban lengkap, akurat, terstruktur, ada contoh "Penjelasan fotosintesis dan respirasi sangat detail dan akurat"
    80-89% (24-26 poin) Sangat Baik: jawaban lengkap dan akurat, minor detail kurang "Jawaban bagus, hanya kurang contoh proses di mitokondria"
    70-79% (21-23 poin) Baik: jawaban inti tepat, tapi kurang detail/penjelasan "Konsep benar, tapi penjelasan respirasi perlu lebih detail"
    60-69% (18-20 poin) Cukup: jawaban inti ada, tapi banyak kekurangan "Jawaban ada, tapi ada kesalahan konsep di bagian..."
    50-59% (15-17 poin) Kurang: jawaban tidak lengkap atau ada kesalahan "Baru jawab sebagian, saran: baca kembali materi"
    0-49% (0-14 poin) Sangat Kurang: jawaban salah atau kosong "Jawaban tidak sesuai pertanyaan" atau "Kosong"

    Langkah 3: Tulis Catatan/Feedback (Opsional)

    Feedback membantu siswa belajar dari kesalahan. Tips:

    • 🎯 Spesifik — Tunjuk bagian mana yang benar/salah
    • 💡 Konstruktif — Berikan saran perbaikan, bukan kritik keras
    • 📌 Ringkas — 2-3 kalimat, tidak perlu panjang
    • ✨ Positif — Mulai dengan yang positif, kemudian perbaikan

    Contoh Feedback Baik:

    "Jawaban Anda sudah bagus! Penjelasan fotosintesis benar dan lengkap.
Untuk respirasi, tambahkan penjelasan di mana proses terjadi (mitokondria).
Kalau selesai, baca lagi contoh di buku hlm 45. Mantul! 👍"

    Hindari Feedback Seperti Ini:

    "Salah. Coba belajar lagi." ❌ (Terlalu kasar, tidak membantu)

    Langkah 4: Simpan Nilai

    1. Pastikan nilai sudah ter-input di field "Nilai Essai"
    2. Catatan sudah lengkap (atau kosongkan jika tidak perlu)
    3. Klik "Simpan Nilai" atau "Submit"

    Sistem akan: - ✅ Menyimpan nilai essai - ✅ Catat siapa penilai (nama Anda) dan kapan - ✅ Otomatis hitung nilai total = PG + Essai - ✅ Pindah ke essai berikutnya (jika ada)

    Lihat Progress Penilaian

    Untuk melihat berapa banyak essai yang sudah dinilai vs belum:

    1. Kembali ke halaman Monitoring Ujian
    2. Di bagian Statistik, lihat: "Sudah Nilai Essai: 8 / 38 (21%)"
    3. Jika 100%, semua essai sudah dinilai dan nilai total sudah final

    Laporan & Analisis Nilai

    Export Nilai

    Untuk keperluan rapor atau analisis lebih lanjut:

    1. Di halaman Monitoring atau Daftar Ujian, cari tombol "Export Nilai" atau "📥"
    2. Pilih format:
    3. Excel (.xlsx) — Untuk edit di Excel/Sheets
    4. PDF (.pdf) — Untuk print atau arsip
    5. CSV (.csv) — Untuk import ke sistem lain
    6. Klik "Download" atau "Export"
    7. File akan tersimpan di komputer Anda

    Tips & Best Practices

    📌 Tips Monitoring Real-Time

    1. Perhatikan Outliers
    2. Siswa yang selesai sangat cepat (< durasi / 2) → Mungkin tidak serius
    3. Siswa yang belum mulai menjelang akhir → Ingat untuk submit

    4. Nilai PG tiba-tiba tinggi untuk siswa rata-rata → Mungkin perlu ditanyakan

    5. Jangan Intervensi Selama Ujian

    6. Biarkan siswa fokus mengerjakan

    7. Hanya intervensi jika ada masalah teknis (disconnect, dll)

    8. Pantau Koneksi Network

    9. Jika ada siswa dengan waktu sisa tiba-tiba loncat/tidak konsisten → Ada lag/disconnect

    10. Beri tahu siswa untuk segera reconnect atau refresh

    11. Siapkan Backup

    12. Jika ada kendala teknis masif, siapkan print-out soal dan buat ujian offline

    ✏️ Tips Menilai Essai

    1. Konsistensi Penilaian
    2. Buat rubrik/kriteria penilaian yang jelas (excellent, good, fair, poor)
    3. Terapkan kriteria sama untuk semua siswa

    4. Jika perlu, baca jawaban di awal untuk set benchmark

    5. Penilaian Objektif

    6. Nilai berdasarkan isi/konsep, bukan "suka tidak suka"
    7. Jika ada kesalahan, tunjuk dengan jelas

    8. Beri nilai sama untuk jawaban yang sama kualitasnya, meski beda siswa

    9. Waktu Penilaian

    10. Jangan nilai terlalu cepat (2-3 soal/menit)
    11. Ambil waktu ~ 5 menit per essai untuk baca teliti + beri nilai + catatan

    12. Total 38 siswa × 2 essai = 76 essai → ~6 jam kerja

    13. Feedback yang Membantu

    14. Fokus pada perbaikan untuk ujian berikutnya
    15. Jangan hanya negatif — mulai dengan positif
    16. Spesifik & actionable: "Baca halaman 50-55" lebih baik daripada "Belajar lebih keras"

    📊 Tips Menganalisis Nilai

    1. Cek Validitas
    2. Apakah distribusi nilai normal (kurva lonceng)?
    3. Jika semua nilai jelek → Soal mungkin terlalu sulit

    4. Jika semua nilai bagus → Soal mungkin terlalu mudah

    5. Identifikasi Siswa yang Perlu Bantuan

    6. Siswa dengan nilai < 70 → Perlu remedial
    7. Siswa dengan nilai < 50 → Perlu intervensi khusus BK

    8. Bandingkan dengan nilai sebelumnya → Ada penurunan signifikan?

    9. Gunakan untuk Refleksi Mengajar

    10. Jika mayoritas salah di soal X → Mungkin topik X tidak dikuasai, review di kelas
    11. Jika nilai essai jauh lebih rendah PG → Siswa kurang mahir menulis/analisis

    Pertanyaan Umum (FAQ)

    Q: Bagaimana jika ada siswa yang disconnect saat ujian?

    A: 1. Sistem akan auto-save jawaban terakhir 2. Siswa bisa reconnect dan lanjut dari mana dia terakhir 3. Durasi tetap berjalan (tidak reset) 4. Jika durasi habis, sistem auto-submit

    Q: Bisakah saya mengubah nilai essai setelah disimpan?

    A: Ya, jika fitur edit tersedia. Beberapa sistem memungkinkan: - Edit nilai essai (jika belum terlalu lama) - Edit catatan guru - Hubungi admin jika sudah kembali nilai ke siswa

    Q: Berapa lama biasanya waktu untuk menilai essai?

    A: Tergantung: - Kompleksitas soal essai - Jumlah siswa - Kualitas jawaban

    Estimasi: 5 menit per essai = ~4-6 jam untuk satu kelas

    Q: Bagaimana jika ada kesalahan dalam soal?

    A: - Sebelum siswa submit: Edit soal di halaman "Kelola Soal" - Setelah siswa submit: Hubungi admin untuk penanganan emergency (biasanya soal dibatalkan untuk semua)

    Q: Dapatkah siswa see nilai essai saya sebelum saya submit?

    A: Tidak. Nilai essai hanya visible untuk siswa SETELAH Anda simpan/submit nilai.

    Q: Apa bedanya nilai "Pending" vs "Final"?

    A: - Pending → Ada essai yang belum dinilai, nilai total belum dihitung akhir - Final → Semua essai sudah dinilai, nilai total sudah final dan bisa di-import ke database nilai akhir

    Q: Bagaimana jika siswa mengeluh nilai essai tidak adil?

    A: 1. Buka halaman detail jawaban siswa + feedback Anda 2. Banding dengan nilai siswa lain (untuk konsistensi) 3. Kalau memang ada kesalahan, edit nilai dan beritahu siswa 4. Dokumentasikan alasan perubahan untuk transparansi

    Q: Bisakah saya lihat apakah siswa telah membaca feedback saya?

    A: Tergantung sistem. Beberapa sistem track: - "Last Read: 28 April 14:30" - Tapi tidak semua sistem memiliki fitur ini
