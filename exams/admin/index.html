    Pengenalan Singkat

    Apa itu Ujian Online Admin?

    Admin Panel Ujian Online adalah backend untuk:

    • ⚙️ Konfigurasi Sistem — Setup parameter ujian global (bobot default, max attempt, durasi default, dll)
    • 📚 Kelola Master Data — CRUD data referensi (Guru, Siswa, Kelas, Mata Pelajaran, Semester, Bank Soal)
    • 👥 Kelola Permissions — Atur siapa bisa akses apa (Guru, Wali Kelas, BK, Kepala Sekolah)
    • 📊 Monitoring Sistem — Lihat statistik ujian, logs, performa
    • 🔧 Maintenance — Backup data, cleanup, update settings
    • 📋 Laporan Sekolah — Generate laporan nilai ujian untuk keperluan administrasi

    Siapa yang Menggunakan?

    Peran Fokus Akses
    Admin Sistem Setup teknis, monitoring, maintenance Full
    Tata Usaha (TU) Data master, laporan, backup Partial (data management)
    Kepala Sekolah Laporan, statistik, monitoring View-Only
    Guru/Wali Kelas Buat ujian, kelola soal, nilai essai Limited (ujian sendiri)

    Akses Panel Admin Ujian

    Login Admin

    1. Buka portal admin: https://edupoin.sekolah.id/admin
    2. Login dengan akun Admin atau Tata Usaha
    3. Di dashboard, cari menu "Ujian Online" atau "Manajemen Ujian"
    4. (Atau akses langsung: https://edupoin.sekolah.id/admin/ujian-online)

    Setup Awal (First Time)

    Checklist Setup Awal

    Untuk implementasi pertama kali, ikuti checklist berikut:

    ☐ 1. Verifikasi Data Master
☐ 2. Konfigurasi Permissions
☐ 3. Setup Parameter Global
☐ 4. Import Bank Soal (jika ada)
☐ 5. Create Ujian Pilot/Testing
☐ 6. Training Guru
☐ 7. Uji Coba Dengan Siswa
☐ 8. Go Live

    Langkah 1: Verifikasi Data Master

    Pastikan data referensi sudah lengkap sebelum membuat ujian.

    Periksa Data Guru

    1. Buka menu "Kelola Master Data" → "Guru"
    2. Pastikan semua guru sudah ter-input dengan:
    3. ✅ NIP / ID
    4. ✅ Nama Lengkap
    5. ✅ Email (untuk login & notifikasi)
    6. ✅ Status Aktif

    Jika ada yang kurang: - Klik "+ Tambah Guru" untuk add baru - Atau upload via Excel jika banyak

    Periksa Data Siswa

    1. Buka menu "Kelola Master Data" → "Siswa"
    2. Filter by Kelas untuk memastikan setiap kelas memiliki siswa
    3. Jika ada yang kurang, import dari sistem sebelumnya atau add manual

    Periksa Data Kelas & Mata Pelajaran

    1. Kelas — Pastikan semua kelas yang ada di sekolah sudah terdaftar (X-1, X-2, XI-1, XI-2, XII-1, dll)
    2. Mata Pelajaran — Pastikan semua mapel sudah ada (Matematika, IPA, Bahasa Indonesia, dll)
    3. Semester — Pastikan semester sudah set (Semester 1, Semester 2)

    Langkah 2: Konfigurasi Permissions

    Tentukan siapa bisa apa di modul Ujian Online.

    Akses "Permissions & Roles"

    1. Menu → "Konfigurasi Sistem" → "Permissions & Roles"
    2. Anda akan melihat tabel role vs permission

    Role vs Permission (Contoh Standar)

    Role ujian.view ujian.create ujian.edit ujian.delete ujian.monitoring ujian.nilai
    Guru ✅ ✅ (ujian sendiri) ✅ ❌ ✅ ✅
    Wali Kelas ✅ ❌ ❌ ❌ ✅ ⚠️ (essai saja)
    Admin ✅ ✅ (all) ✅ ✅ ✅ ✅
    Kepala Sekolah ✅ ❌ ❌ ❌ ✅ (view) ❌
    Siswa ✅ ❌ ❌ ❌ ❌ ❌

    Jika perlu modifikasi, klik permission yang ingin diubah dan update.

    Langkah 3: Setup Parameter Global

    Konfigurasi default untuk semua ujian baru yang dibuat guru.

    Akses "Setting Global"

    1. Menu → "Konfigurasi Sistem" → "Setting Global"
    2. Isi parameter berikut:
    📝 FORM SETTING GLOBAL:

┌─ Durasi Default ────────────────────────────┐
│ Durasi Ujian Default: [90] menit           │
│ (Guru bisa override per ujian)              │
└─────────────────────────────────────────────┘

┌─ Soal & Bobot ──────────────────────────────┐
│ Jumlah Soal Default: [5] soal              │
│ Total Bobot Max: [100] poin                │
│ PG Auto-Grading: [✅ Aktif]                │
│ Essai Manual Grading: [✅ Aktif]           │
└─────────────────────────────────────────────┘

┌─ Attempt & Retry ───────────────────────────┐
│ Max Attempt (Default): [1] kali            │
│   (0 = Hanya 1x, tidak boleh retry)        │
│   (1 = Boleh 2x, dst)                      │
│ Strategi Nilai Retry: [Terbaik ▼]          │
│   - Terbaik: Ambil nilai tertinggi         │
│   - Terakhir: Ambil nilai terakhir         │
└─────────────────────────────────────────────┘

┌─ Tampilan & Interface ───────────────────────┐
│ Tampilkan Hasil Langsung: [✅ Ya]           │
│   (Siswa bisa lihat nilai PG langsung)     │
│ Tampilkan Jawaban Benar: [❌ Tidak]        │
│   (Jawaban benar baru terlihat setelah...) │
│ Soal Random/Acak: [❌ Tidak]               │
│   (Setiap siswa soal berbeda urutan)       │
│ Opsi Jawaban Random: [❌ Tidak]            │
│   (Opsi PG diacak per siswa)               │
└─────────────────────────────────────────────┘

┌─ Notifikasi ────────────────────────────────┐
│ Kirim Email Saat Ujian Dimulai: [✅ Ya]   │
│ Kirim Reminder 1 Jam Sebelum: [✅ Ya]     │
│ Kirim Notif Saat Essai Dinilai: [✅ Ya]   │
└─────────────────────────────────────────────┘

[Simpan Setting]  [Reset ke Default]

    Penjelasan Tiap Setting:

    • Durasi Default — Semua ujian baru akan default 90 menit, bisa diubah per ujian
    • Total Bobot Max — Guru tidak boleh exceed 100 poin total per ujian
    • Auto-Grading PG — Soal PG dinilai otomatis saat submit
    • Essai Manual — Soal essai harus dinilai guru manual
    • Max Attempt — Berapa kali siswa boleh ngambil ujian (0 = 1x, 1 = 2x, dst)
    • Strategi Nilai — Jika retry, ambil nilai terbaik atau nilai terakhir?
    • Random Soal/Opsi — Untuk keamanan (agar siswa tidak copy, tapi biasanya off)

    Klik "Simpan Setting" setelah konfigurasi selesai.

    Langkah 4: Import Bank Soal (Opsional)

    Jika sekolah sudah memiliki bank soal dari sistem sebelumnya:

    1. Menu → "Kelola Master Data" → "Bank Soal"
    2. Klik "📥 Import Bank Soal"
    3. Upload file Excel dengan format: 
      No | Kode | Pertanyaan | Opsi A | Opsi B | Opsi C | Opsi D | Jawaban Benar | Mapel | Tingkat
1  | M01  | Berapa hasil ... | 10 | 11 | 12 | 13 | B | Matematika | Easy
    4. Klik "Preview & Import" untuk verifikasi
    5. Jika OK, klik "Finish Import" — Sistem akan import semua soal

    Langkah 5: Create Ujian Pilot/Testing

    Sebelum go live, buat 1 ujian test untuk testing dengan guru & siswa.

    1. Minta guru untuk buat ujian testing (atau admin buat langsung sebagai test)
    2. Jalankan dengan kelas kecil (10-20 siswa) sebagai pilot
    3. Catat feedback: interface OK? Soal tayang dengan baik? Timer berfungsi?
    4. Perbaiki issue yang ditemukan

    Langkah 6-8: Training, Testing, Go Live

    Setelah pilot OK: - ✅ Training guru: cara buat ujian, manage soal, nilai essai - ✅ Uji coba dengan semua siswa 1-2 kelas - ✅ Go live untuk seluruh sekolah

    Konfigurasi Sistem

    Ujian Template

    Buat template ujian yang bisa di-reuse:

    Menu → "Konfigurasi Sistem" → "Template Ujian"

    Contoh Template "UTS Standard":
├─ Durasi: 90 menit
├─ Soal: 5 (3 PG + 2 Essai)
├─ Bobot: 100 poin (PG 40, Essai 60)
├─ Max Attempt: 0 (1x saja)
├─ Random Soal: Tidak
└─ Essai Manual Grade: Ya

Contoh Template "Pop Quiz":
├─ Durasi: 30 menit
├─ Soal: 3 (3 PG)
├─ Bobot: 30 poin
├─ Max Attempt: 1 (boleh 2x)
├─ Random Soal: Ya
└─ Essai: Tidak ada

    Guru bisa pilih template ketika buat ujian baru → lebih cepat setup.

    Pertanyaan Umum (FAQ)

    Q: Bagaimana jika ada kesalahan data guru di master data?

    A: 1. Buka menu Guru Management 2. Cari guru yang salah data-nya 3. Klik Edit 4. Perbaiki data (NIP, nama, email, dll) 5. Simpan 6. Email guru untuk notify perubahan (jika ada)

    Q: Berapa sering saya harus backup database?

    A: - Minimal: 1x sehari (misalnya, jam 23:00) - Recommended: Backup otomatis setiap hari + manual backup setelah "big event" (ujian besar, import data masif, dll) - Retention: Simpan minimal 7 hari backup

    Q: Bagaimana jika server lambat saat ujian berlangsung?

    A: 1. Short term: Klik "Clear Cache" di maintenance 2. Monitor: Lihat Activity Logs apakah ada activity mencurigakan 3. Check: System Health Check — apakah ada resource yang overloaded? 4. Long term: Upgrade server resources atau optimize database

    Q: Dapatkah saya reset password guru/siswa?

    A: Tergantung sistem: - Jika sistem terintegrasi dengan auth system sekolah (LDAP/AD) → Hubungi admin network - Jika standalone → Admin bisa reset via "User Management" (biasanya di sebelah "Master Data")

    Q: Bagaimana jika guru lupa cara buat ujian?

    A: 1. Hubungi guru untuk provide dokumentasi/video tutorial (sudah ada di docs) 2. Atau setup ujian untuk guru & transfer ownership 3. Jika banyak guru yang butuh bantuan → Selenggarakan training lagi

    Q: Dapatkah saya export laporan ke format berbeda (PDF, CSV, dll)?

    A: Ya, di menu "Laporan Nilai": 1. Pilih ujian & kelas 2. Pilih format: Excel / PDF / CSV 3. Klik Download

    Q: Bagaimana backup & restore jika ada disaster?

    A: Backup: - Aktifkan auto-backup (setiap hari jam 23:00) - Backup bisa disimpan di cloud atau external storage

    Restore: - Jika ada issue, hubungi admin/IT - Restore dari backup terakhir yang OK - Proses restore biasanya 10-30 menit tergantung size database
