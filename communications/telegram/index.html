    Pengenalan Singkat

    Apa itu Notifikasi Telegram di EduPoin?

    Telegram adalah aplikasi pesan gratis yang digunakan EduPoin untuk mengirimkan notifikasi penting ke Orang Tua tentang:

    • 🔴 Siswa tidak hadir tanpa keterangan (Alpha)
    • 🎒 Siswa memiliki pelanggaran tata tertib
    • 📢 Pengumuman penting dari sekolah
    • Dan informasi lainnya

    Mengapa Telegram?

    ✅ Gratis — Tidak ada biaya langganan
    ✅ Cepat — Pesan real-time, tidak ada delay
    ✅ Aman — Enkripsi end-to-end
    ✅ Tersedia di semua perangkat — Mobile, desktop, web

    Apa yang Perlu Saya Lakukan?

    Sebagai Orang Tua, Anda harus: 1. ✅ Install aplikasi Telegram di smartphone 2. ✅ Dapatkan Chat ID Telegram Anda 3. ✅ Daftarkan Chat ID ke sistem EduPoin

    Panduan Orang Tua: Mendapatkan Notifikasi

    Langkah 1: Install Aplikasi Telegram

    Untuk Smartphone (Android & iOS)

    1. Buka App Store (iPhone) atau Google Play (Android)
    2. Cari "Telegram" (dibuat oleh Telegram LLC)
    3. Klik tombol "Install" atau "Get"
    4. Tunggu hingga selesai terinstall
    5. Klik "Open" untuk membuka aplikasi

    Untuk Desktop (Windows/Mac/Linux)

    1. Buka browser, kunjungi https://telegram.org/apps
    2. Download aplikasi sesuai sistem operasi Anda
    3. Install dan buka Telegram

    Langkah 2: Buat Akun Telegram (Jika Belum Punya)

    1. Buka aplikasi Telegram
    2. Klik "Start Messaging" atau "Sign Up"
    3. Masukkan nomor telepon Anda (gunakan nomor aktif)
    4. Telegram akan mengirim kode verifikasi 5 digit via SMS
    5. Masukkan kode verifikasi
    6. Isi nama lengkap dan klik "Sign Up"

    ✅ Akun Telegram Anda sekarang aktif!

    Langkah 3: Dapatkan Chat ID Anda

    Chat ID adalah nomor unik yang digunakan EduPoin untuk mengirim pesan ke Anda. Ada dua cara:

    Cara 1: Menggunakan Bot Telegram (Mudah)

    1. Buka aplikasi Telegram
    2. Cari @userinfobot di search (ketik di kolom pencarian atas)
    3. Klik bot tersebut dan klik "START" atau ketik /start
    4. Bot akan mengirimkan pesan dengan informasi akun Anda, termasuk User ID
    5. User ID yang tampil = Chat ID Anda

    Contoh respons bot: 

    Your ID: 123456789
First Name: Ibu Siti

    Chat ID Anda = 123456789

    Cara 2: Menggunakan URL API (Alternatif)

    1. Mulai percakapan dengan bot @BotFather
    2. Ikuti panduan di bagian Admin untuk mendapatkan Bot Token
    3. Buka URL berikut di browser (ganti TOKEN dengan token bot): 
      https://api.telegram.org/botTOKEN/getUpdates
    4. Cari nilai "id" di bawah "chat" — itu adalah Chat ID Anda

    Langkah 4: Daftarkan Chat ID ke Sistem EduPoin

    Setelah mendapatkan Chat ID, daftarkan ke sekolah:

    Opsi A: Melalui Admin/TU Sekolah (Cara Paling Mudah)

    1. Hubungi Tata Usaha (TU) atau Admin Sistem sekolah
    2. Berikan:
    3. Nama lengkap Anda
    4. Nomor induk siswa anak Anda
    5. Nomor telepon aktif Anda
    6. Chat ID Telegram Anda (dari langkah 3)
    7. Admin akan mendaftarkan Chat ID Anda ke sistem
    8. ✅ Selesai! Anda akan mulai menerima notifikasi

    Opsi B: Melalui Aplikasi EduPoin (Jika Ada Akses)

    1. Login ke aplikasi EduPoin dengan akun Anda (jika ada)
    2. Buka menu "Pengaturan" atau "Profil"
    3. Cari bagian "Notifikasi Telegram" atau "Chat ID"
    4. Paste Chat ID Telegram Anda
    5. Klik "Simpan" atau "Verifikasi"
    6. ✅ Selesai!

    Langkah 5: Verifikasi (Jika Diminta)

    Setelah mendaftar, beberapa sekolah mungkin meminta verifikasi:

    1. Buka aplikasi Telegram
    2. Cari @edupoinbot (atau nama bot sekolah Anda)
    3. Klik "START"
    4. Sistem akan mengirim kode verifikasi ke Telegram Anda
    5. Masukkan kode verifikasi di website atau aplikasi EduPoin
    6. ✅ Verifikasi selesai!

    Jenis-Jenis Notifikasi

    🔴 Notifikasi Presensi Alpha

    Kapan dikirim: Saat anak Anda tidak hadir (Alpha) di kelas

    Contoh pesan: 

    ⚠️ NOTIFIKASI PRESENSI EduPoin

Nama Siswa: Budi Santoso
Kelas: X-A
Tanggal: Senin, 28 April 2025
Jam Pelajaran: 08:00 - 09:00
Mata Pelajaran: Matematika
Status: ALPHA (Tidak Hadir Tanpa Keterangan)

👨‍🏫 Guru: Ibu Siti Rahayu
Waktu Input: 08:15

📞 Hubungi BK jika ada informasi lebih lanjut.

    Tindakan: - Hubungi anak Anda untuk tahu di mana dia - Hubungi sekolah (BK/Wali Kelas) untuk klarifikasi - Jika ada izin, lapor ke BK untuk diinput ulang

    🚨 Notifikasi Pelanggaran Tata Tertib

    Kapan dikirim: Saat anak Anda memiliki pelanggaran tata tertib

    Contoh pesan: 

    ⚠️ NOTIFIKASI PELANGGARAN TATA TERTIB EduPoin

Nama Siswa: Budi Santoso
Kelas: X-A
Tanggal: Senin, 28 April 2025

Jenis Pelanggaran: Tidak Memakai Seragam Lengkap
Poin: 5
Status: Penanganan Awal

👨‍🏫 Guru Pemutus: Pak Ahmad Wijaya
Catatan: Budi tidak memakai dasi di hari Senin

🎯 Tahap Berikutnya: Wali Kelas akan melakukan pembinaan

📞 Hubungi Wali Kelas untuk diskusi lebih lanjut.

    Tindakan: - Tanyakan ke anak tentang pelanggaran tersebut - Beri pembinaan kepada anak - Pantau poin pelanggaran agar tidak terakumulasi

    Kapan dikirim: Saat ada pengumuman penting dari sekolah

    Panduan Admin: Setup Bot Telegram

    📌 Untuk Admin Sistem / Kepala Sekolah

    Jika Anda adalah Admin Sistem atau TU, ada 2 guide yang perlu Anda baca:

    1. TELEGRAM.md — Setup Bot Token & Konfigurasi Telegram (teknis)
    2. ORANGTUA_USER_GUIDE.md — Mengelola Data Orang Tua & Chat ID (operasional) ⭐ BACA INI DULU

    Ringkas Singkat Setup

    Ikuti langkah ini untuk setup Bot Telegram:

    Langkah 1: Buat Bot via BotFather

    1. Buka aplikasi Telegram
    2. Cari @BotFather (bot resmi Telegram)
    3. Klik "START" atau ketik /newbot
    4. BotFather akan bertanya nama bot: 
      What do you want your bot to be called?
    5. Ketik nama bot, contoh: EduPoin SMAN 1 Jakarta
    6. BotFather akan bertanya username bot: 
      Good. Now let's choose a username for your bot.
It must end in 'bot'. For example, TetrisBot or tetris_bot.
    7. Ketik username, contoh: edupoin_sman1_bot (harus berakhiran _bot)
    8. BotFather akan memberikan Bot Token, contoh: 
      Done! Congratulations on your new bot. 
You will find it at https://t.me/edupoin_sman1_bot

1234567890:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

    ⚠️ SIMPAN TOKEN INI DENGAN AMAN — Ini kunci akses bot Anda!

    Langkah 2: Setup Bot Token di EduPoin

    1. Login ke Admin Panel EduPoin sebagai Admin/TU
    2. Buka menu "Pengaturan" → "Notifikasi" atau "Telegram"
    3. Paste Bot Token dari langkah 1
    4. Klik "Simpan" dan "Test" untuk verifikasi
    5. Jika berhasil, akan ada pesan: ✅ "Bot Token Valid"

    Langkah 3: Dapatkan Chat ID Admin

    Untuk testing dan dokumentasi, Anda juga perlu Chat ID Admin:

    1. Buka aplikasi Telegram
    2. Cari bot yang Anda buat (contoh: @edupoin_sman1_bot)
    3. Klik "START"
    4. Buka URL di browser (ganti TOKEN): 
      https://api.telegram.org/botTOKEN/getUpdates
    5. Cari "id" di bawah "chat" — itu adalah Chat ID Admin Anda

    Langkah 4: Konfigurasi di Sistem EduPoin

    1. Di menu Pengaturan Telegram, isi:
    2. Bot Token: [Token dari BotFather]
    3. Chat ID Admin: [Chat ID Admin]
    4. Enable Notifications: ✅ ON

    5. Notification Rules:

      • ✅ Kirim saat Alpha (tidak hadir tanpa keterangan)
      • ✅ Kirim saat Pelanggaran
      • ✅ Kirim saat Pengumuman

    6. Klik "Simpan Pengaturan"

    Langkah 5: Test Notifikasi (Opsional)

    Untuk memastikan bot bekerja:

    1. Klik tombol "Kirim Test"
    2. Periksa Telegram admin — harus ada pesan test
    3. Jika berhasil, semua pengaturan benar ✅

    Pertanyaan Umum (FAQ)

    ❓ Bagaimana jika saya belum punya Telegram?

    Jawab: 1. Install aplikasi Telegram dari App Store/Play Store 2. Buat akun baru dengan nomor telepon Anda 3. Daftarkan Chat ID ke sekolah (lihat Langkah 4 di atas)

    Proses ini gratis dan hanya butuh 5 menit.

    ❓ Apakah Telegram aman untuk data anak saya?

    Jawab: YA, Telegram aman karena: - ✅ Pesan terenkripsi - ✅ EduPoin hanya mengirim info penting (tidak ada password) - ✅ Chat ID Anda hanya diketahui sekolah - ✅ Anda bisa blokir bot kapan saja

    Namun jangan share Chat ID ke orang lain.

    ❓ Bisakah saya menerima notifikasi dari beberapa anak (di sekolah yang sama)?

    Jawab: YA. Daftarkan satu Chat ID Anda untuk semua anak. Sistem akan otomatis mengirim notifikasi untuk setiap anak dengan info: "Nama Siswa: [nama anak]"

    ❓ Bagaimana jika saya tidak ingin menerima notifikasi?

    Jawab: - Opsi 1: Hubungi Admin untuk menonaktifkan Chat ID Anda - Opsi 2: Di aplikasi Telegram, blokir bot dengan klik "Block" (tapi Anda tidak akan terima notifikasi lagi)

    Jangan blokir jika masih ingin terima notifikasi penting.

    ❓ Apa yang harus saya lakukan jika Chat ID saya salah?

    Jawab: Hubungi Admin/TU untuk koreksi. Berikan: - Nama Anda - Nomor induk siswa anak - Chat ID yang benar (dapatkan ulang lewat @userinfobot)

    Admin akan update dalam sistem dalam 1-2 jam kerja.

    ❓ Bagaimana jika saya berganti nomor telepon?

    Jawab: 1. Di Telegram, buka "Settings" → "Change Phone Number" 2. Ikuti proses verifikasi 3. Chat ID Anda akan tetap sama 4. Tidak perlu update di EduPoin

    ❓ Berapa lama notifikasi sampai ke saya?

    Jawab: Biasanya kurang dari 5 detik setelah guru input data. Jika lebih lama, cek: - Koneksi internet Anda stabil? - Telegram sudah aktif/login? - Telegram notification aktif di pengaturan OS?

    ❓ Bisakah saya reply pesan notifikasi dari EduPoin?

    Jawab: TIDAK — Pesan dari EduPoin adalah one-way notification, Anda tidak bisa reply. Untuk komunikasi, hubungi langsung Wali Kelas atau BK melalui nomor telepon yang ada di pesan.

    ❓ Apakah ada pesan spam atau notifikasi yang tidak perlu?

    Jawab: EduPoin dirancang untuk hanya kirim notifikasi penting: - ❌ TIDAK kirim setiap siswa hadir (hanya jika Alpha) - ❌ TIDAK kirim pelanggaran ringan (hanya serius) - ✅ HANYA kirim yang penting & membutuhkan perhatian orang tua

    Jika ada notifikasi yang mengganggu, hubungi Admin untuk adjust pengaturan.

    ❓ Bagaimana jika anak saya sakit atau izin, apakah masih dapat notifikasi Alpha?

    Jawab: TIDAK. Sistem cerdas: - Jika ada data "Izin" atau "Sakit" → Status bukan Alpha → Tidak kirim notifikasi - Jika hanya "Alpha" tanpa izin → Kirim notifikasi

    Jadi pastikan BK input status izin/sakit dengan benar di sistem.
