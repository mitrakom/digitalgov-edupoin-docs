    Pengenalan Singkat

    Modul Akun Siswa adalah fitur di EduPoin untuk mengelola login account siswa. Modul ini terpisah dari data biodata siswa — artinya Anda harus terlebih dahulu membuat data siswa di modul Data Siswa sebelum membuat akunnya.

    🎯 Fitur Utama

    Fitur Deskripsi
    Buat Akun Siswa Membuat akun login untuk siswa yang sudah terdaftar dalam biodata
    Pilih Siswa Existing Hanya siswa yang belum punya akun yang dapat dipilih
    Set Username & Password Admin menentukan username dan password akun siswa
    Auto Role Siswa Role "Siswa" otomatis di-assign saat akun dibuat
    Lihat Akun Siswa Melihat daftar semua akun siswa yang sudah dibuat
    Edit Akun Siswa Mengubah username, email, atau password akun siswa

    ✨ Manfaat Pemisahan Biodata & Akun

    ✓ Fleksibel: Siswa bisa didaftarkan biodata dahulu, akun dibuat kemudian
    ✓ Aman: Mencegah kesalahan — biodata tidak akan hilang jika lupa akun
    ✓ Terukur: Admin dapat mengontrol kapan siswa mendapat akses login
    ✓ Efisien: Data siswa tetap ada meski akun dihapus (untuk audit trail)
    ✓ Terstruktur: Alur workflow jelas — biodata dulu, akun kemudian

    Workflow Pembuatan Akun Siswa

    Langkah-Langkah Umum

    1. ✅ Data Siswa Sudah Ada
   ↓ (Modul "Personil → Siswa")

2. 🔐 Buat Akun Siswa
   ↓ (Modul "Sistem & Pengguna → Akun Siswa")

3. ✓ Siswa Bisa Login
   ↓

4. 📚 Siswa Akses Fitur Akademik
   ├─ Presensi
   ├─ Nilai & Raport
   ├─ Pengajuan Izin
   └─ Dashboard Siswa

    ❌ Yang TIDAK Perlu Dilakukan

    • ❌ Tidak perlu membuat user di menu "Akun Internal"
    • ❌ Tidak perlu set role manual — otomatis "Siswa"
    • ❌ Tidak perlu edit data biodata siswa dari sini — gunakan "Personil → Siswa"

    Akses Modul Akun Siswa

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda (harus Admin)
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Akun Siswa

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri)
    3. Cari grup "Sistem & Pengguna" (bagian bawah)
    4. Di bawahnya, klik "Akun Siswa"
    5. Anda akan masuk ke halaman daftar akun siswa

    Direct URL: 

    https://edupoin.sekolah.id/admin/siswa-accounts
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Membuat Akun Siswa Baru

    Prasyarat

    Pastikan siswa sudah terdaftar di: - Menu Personil → Siswa - Siswa belum punya akun login (field user_id kosong)

    Langkah 1: Buka Halaman Daftar Akun Siswa

    Ikuti petunjuk di bagian Akses Modul Akun Siswa

    Langkah 2: Klik Tombol "Buat Akun Siswa"

    Di halaman daftar, Anda akan melihat tombol berwarna biru bernama "+ Buat Akun Siswa" atau "Buat" di sudut kanan atas.

    Klik tombol tersebut.

    Langkah 3: Isi Form Pembuat Akun Siswa

    Anda akan melihat form dengan kolom berikut:

    Data Siswa ⭐ WAJIB

    • Deskripsi: Pilih siswa dari dropdown
    • Cara Memilih:
    • Klik tombol "Pilih salah satu opsi"
    • Daftar siswa akan tampil (hanya siswa tanpa akun)
    • Cari nama siswa atau scroll, lalu klik nama siswa
    • Catatan:
    • Jika tidak ada siswa di daftar = semua siswa sudah punya akun
    • Jika siswa yang dicari tidak ada = siswa belum terdaftar di modul Data Siswa

    Username ⭐ WAJIB

    • Deskripsi: Username untuk login siswa (harus unik)
    • Rekomendasi:
    • Gunakan NISN (Nomor Induk Siswa Nasional) — mudah diingat
    • Contoh: 1001234567
    • Atau: siswa_nama_20260602
    • Validasi:
    • Tidak boleh kosong
    • Tidak boleh duplikat dengan siswa/user lain
    • Maksimal 100 karakter

    Email (Opsional)

    • Deskripsi: Email siswa (untuk reset password, notifikasi, dll)
    • Format: nama@email.com
    • Catatan: Bisa dikosongkan, bisa ditambah nanti

    Password ⭐ WAJIB

    • Deskripsi: Password awal untuk login
    • Rekomendasi:
    • Minimal 8 karakter
    • Gunakan kombinasi huruf, angka, simbol
    • Contoh: SiswaBaru2026! atau password123
    • Catatan:
    • Password tidak ditampilkan ulang setelah save
    • Siswa dapat ganti password setelah login (opsional)
    • Admin dapat reset password kapan saja

    Langkah 4: Validasi Input

    Sebelum klik "Buat", pastikan:

    • ✅ Data Siswa sudah dipilih
    • ✅ Username terisi (dan belum ada yang sama)
    • ✅ Password terisi (minimal 8 karakter)
    • ❌ Kolom berwarna merah = error, harus diisi

    Langkah 5: Klik Tombol "Buat"

    Jika semua kolom valid, klik tombol "Buat" di bagian bawah form.

    Hasil: - ✅ Akun siswa berhasil dibuat - ✅ Role "Siswa" otomatis ter-assign - ✅ Halaman akan redirect ke detail akun siswa

    Langkah 6: Verifikasi Akun Siswa

    Setelah redirect, Anda akan melihat:

    • ✅ Username siswa
    • ✅ Email (jika ada)
    • ✅ Role = "Siswa" ✓
    • ✅ Tanggal pembuatan akun

    Siswa sekarang dapat login dengan: - Username: [sesuai yang Anda input] - Password: [sesuai yang Anda input]

    Panduan: Mengelola Akun Siswa

    Lihat Daftar Akun Siswa

    1. Buka menu Sistem & Pengguna → Akun Siswa
    2. Anda akan melihat tabel dengan kolom:
    3. Siswa: Nama siswa
    4. Username: Username login
    5. Email: Email (jika ada)
    6. Aksi: Tombol Edit/Delete
    7. Scroll kanan untuk melihat kolom lain

    Cari Akun Siswa

    Di halaman daftar, gunakan kotak "Search / Cari" untuk: - Mencari nama siswa - Mencari username - Mencari email

    Contoh: ketik siswa1 atau 1001234567 atau siswa@email.com

    Edit Akun Siswa

    Untuk mengubah username, email, atau password:

    1. Buka daftar akun siswa
    2. Cari akun siswa yang ingin diedit
    3. Klik tombol "Edit" (atau nama siswa)
    4. Anda akan masuk ke halaman edit
    5. Ubah field yang diperlukan:
    6. Username: Username baru (harus unik)
    7. Email: Email baru (opsional)
    8. Password: Password baru (opsional, biarkan kosong jika tidak ingin ubah)
    9. Klik tombol "Simpan" atau "Perbarui"

    Catatan Edit: - Username tidak bisa kosong - Jika ubah password, siswa harus login pakai password baru - Email dapat dikosongkan

    Hapus Akun Siswa

    ⚠️ HATI-HATI! Operasi ini tidak dapat dibatalkan.

    Untuk menghapus akun siswa:

    1. Buka daftar akun siswa
    2. Cari akun siswa yang ingin dihapus
    3. Klik tombol "Delete" atau ikon tempat sampah di kolom Aksi
    4. Sistem akan minta konfirmasi: "Apakah Anda yakin?"
    5. Klik "Hapus" untuk confirm

    Hasil Penghapusan: - ❌ Akun siswa dihapus - ✅ Data biodata siswa tetap ada (untuk audit trail) - ❌ Siswa tidak bisa login lagi - ✅ Riwayat presensi, nilai, dll tetap tersimpan

    Tips & Best Practice

    🎯 Tips Praktis

    1. Gunakan NISN untuk Username
    2. NISN sudah unik di tingkat nasional
    3. Mudah diingat siswa

    4. Memudahkan rekonsiliasi data dengan database pusat

    5. Password Default

    6. Jangan gunakan password yang terlalu mudah (seperti 123456)
    7. Jangan pakai nama siswa atau NISN sebagai password

    8. Contoh password yang baik: Siswa_NISN_20260602 atau Welcome2026!

    9. Batch Import (untuk sekolah besar)

    10. Jika punya banyak siswa, bisa minta feature bulk import ke IT

    11. Lebih efisien daripada satu-satu

    12. Komunikasi ke Siswa

    13. Siapkan kertas berisi username + password siswa
    14. Bagikan saat Anda membuat akunnya

    15. Ajarkan siswa cara login dan ubah password sendiri

    16. Reset Password

    17. Siswa bisa reset password sendiri via login page (forgot password)
    18. Jika lupa, admin bisa edit di sini dan set password baru

    ⚠️ Best Practice Keamanan

    • ✅ Jangan share password di sistem lain
    • ✅ Ganti password default setelah siswa pertama kali login
    • ✅ Hindari pattern password yang sama untuk semua siswa
    • ✅ Monitor login jika ada akun yang mencurigakan
    • ✅ Backup data secara berkala

    Pertanyaan Umum (FAQ)

    Q: Apa bedanya "Data Siswa" dan "Akun Siswa"?

    A: - Data Siswa = Biodata (nama, NISN, tanggal lahir, alamat, dll) - Akun Siswa = Login account (username, password, untuk akses fitur)

    Keduanya terpisah. Anda buat biodata dulu, akun dibuat kemudian.

    Q: Bagaimana jika siswa sudah terdaftar tapi belum punya akun?

    A: Buat akun di modul Akun Siswa: 1. Buka Sistem & Pengguna → Akun Siswa 2. Klik "Buat Akun Siswa" 3. Pilih siswa → set username + password → Buat

    Q: Bisa gak buat akun siswa dari menu "Data Siswa"?

    A: Tidak. Menu "Data Siswa" hanya untuk biodata. Akun dibuat di menu "Akun Siswa" yang terpisah.

    Q: Siswa mana saja yang bisa dipilih saat buat akun?

    A: Hanya siswa yang: - ✅ Sudah terdaftar di Personil → Siswa - ✅ Belum punya akun (field user_id kosong)

    Jika siswa tidak muncul di dropdown, berarti: - ❌ Siswa belum terdaftar biodata (buat di Data Siswa dulu) - ❌ Siswa sudah punya akun (ubah akun di Edit, jangan buat baru)

    Q: Apa yang terjadi jika saya hapus akun siswa?

    A: - ❌ Akun login siswa dihapus — siswa tidak bisa login - ❌ Role "Siswa" dihapus - ✅ Data biodata siswa tetap ada - ✅ Riwayat presensi, nilai, pelanggaran tetap ada (untuk laporan)

    Jadi data akademik aman, hanya akun login yang dihapus.

    Q: Bisakah siswa ganti password sendiri setelah login?

    A: Ya, siswa bisa: 1. Login ke aplikasi 2. Klik profile/menu pengguna (di atas atau sudut halaman) 3. Pilih "Ubah Password" atau "Settings" 4. Masukkan password lama + password baru

    Q: Berapa lama username/password berlaku?

    A: Tidak ada batasan waktu. Username dan password berlaku terus sampai: - Admin hapus akun - Admin ubah username/password - Siswa ganti password sendiri

    Q: Jika lupa password siswa, bagaimana?

    A: Admin dapat reset: 1. Buka daftar Akun Siswa 2. Cari akun siswa → Klik Edit 3. Kosongkan field Password atau isi password baru 4. Klik Simpan 5. Siswa sekarang bisa login dengan password baru

    Alternatif: Siswa klik "Lupa Password" saat login (jika punya email terdaftar).

    Q: Bisa tidak ubah role dari "Siswa" menjadi yang lain?

    A: Tidak disarankan dan tidak perlu. Role "Siswa" sudah fixed untuk akun siswa.

    Jika ingin buat akun dengan role berbeda (Guru, Admin, TU, dll), gunakan menu "Akun Internal" (untuk guru/tendik), bukan "Akun Siswa".

    Q: Apakah buat akun siswa bisa di-batch / import dari file?

    A: Untuk versi ini: hanya manual satu per satu.

    Fitur import/bulk create dapat diminta ke tim IT untuk development.
