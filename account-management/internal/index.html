    Pengenalan Singkat

    Modul Akun Internal adalah fitur di EduPoin untuk mengelola login account Guru dan Staf Sekolah (Tendik). Modul ini terpisah dari data biodata — artinya Anda harus terlebih dahulu membuat data guru/tendik di modul masing-masing sebelum membuat akunnya.

    🎯 Fitur Utama

    Fitur Deskripsi
    Buat Akun Internal Membuat akun login untuk guru/tendik yang sudah terdaftar
    Pilih Sumber Akun Pilih data dari Guru atau Tendik (terpisah)
    Auto Role Assignment Role otomatis sesuai sumber (Guru, TU, Admin, dll)
    Set Username & Password Admin menentukan username dan password
    Lihat Akun Internal Melihat daftar semua akun internal
    Edit Akun Internal Mengubah username, email, password, atau role

    ✨ Manfaat Pemisahan Biodata & Akun

    ✓ Fleksibel: Guru/tendik bisa didaftarkan biodata dahulu, akun dibuat kemudian
    ✓ Terukur: Admin mengontrol kapan guru/tendik mendapat akses sistem
    ✓ Aman: Biodata tidak akan hilang jika akun dihapus
    ✓ Efisien: Mudah ganti role atau suspend akses tanpa hapus data
    ✓ Professional: Workflow terstruktur — biodata dulu, akun kemudian

    Perbedaan Jalur: Guru vs Tendik

    📌 Jalur GURU

    Kapan digunakan: Membuat akun untuk guru pengajar

    Aspek Detail
    Data Sumber Data Guru (Personil → Guru)
    Role Default "Guru"
    Role Tambahan "Wali Kelas" (jika guru adalah wali kelas)
    Username Saran NIP (Nomor Induk Pegawai) atau nama pendek
    Password Saran NIP atau password kuat custom
    Akses Fitur akademik (presensi, nilai, RPP, dll)

    Contoh: - Nama: Budi Santoso - NIP: 198501012010012004 - Username: 198501012010012004 atau budi.santoso - Password: NIP_Aman2026 atau password kuat lainnya - Role: Guru + (Wali Kelas jika applicable)

    👔 Jalur TENDIK

    Kapan digunakan: Membuat akun untuk staf administratif

    Aspek Detail
    Data Sumber Data Tendik (Personil → Tendik)
    Role Pilihan TU, Admin, Kesiswaan, BK, dll
    Role Default Sesuai pilihan saat buat akun
    Username Saran Singkatan jabatan + nama atau nama saja
    Password Saran Password kuat custom
    Akses Fitur administrasi sesuai role

    Contoh: - Nama: Rina Wati - Jabatan: Tata Usaha (TU) - Username: rina.wati atau tu.rina - Password: TU_Aman2026 - Role: TU

    Workflow Pembuatan Akun Internal

    Langkah-Langkah Umum

    JALUR GURU:
1. ✅ Data Guru Sudah Ada
   ↓ (Modul "Personil → Guru")

2. 🔐 Buat Akun Internal (Guru)
   ↓ (Modul "Sistem & Pengguna → Akun Internal")

3. ✓ Guru Bisa Login
   ↓

4. 📚 Guru Akses Fitur Akademik
   ├─ Presensi
   ├─ Input Nilai
   ├─ RPP & Modul Ajar
   └─ Dashboard Guru

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JALUR TENDIK:
1. ✅ Data Tendik Sudah Ada
   ↓ (Modul "Personil → Tendik")

2. 🔐 Buat Akun Internal (Tendik)
   ↓ (Modul "Sistem & Pengguna → Akun Internal")

3. ✓ Tendik Bisa Login
   ↓

4. 🏢 Tendik Akses Sesuai Role
   ├─ TU: Master data, Import siswa
   ├─ Admin: Sistem & keamanan
   ├─ Kesiswaan: Pelanggaran, perizinan
   └─ BK: Konseling, monitoring siswa

    ❌ Yang TIDAK Perlu Dilakukan

    • ❌ Tidak perlu membuat user di menu "Akun Siswa" untuk guru/tendik
    • ❌ Tidak perlu set password di modul Data Guru/Tendik — set di sini
    • ❌ Tidak perlu edit role secara manual jika bisa otomatis

    Akses Modul Akun Internal

    🔐 Login ke Aplikasi

    1. Buka aplikasi EduPoin di browser (sesuaikan URL sekolah Anda)
    2. Masukkan Username/Email Anda (harus Admin)
    3. Masukkan Password Anda
    4. Klik tombol Masuk

    📍 Navigasi ke Modul Akun Internal

    Jika berhasil login:

    1. Anda akan melihat dashboard Admin Panel
    2. Lihat menu di sidebar (bagian kiri)
    3. Cari grup "Sistem & Pengguna" (bagian bawah)
    4. Di bawahnya, klik "Akun Internal"
    5. Anda akan masuk ke halaman daftar akun internal

    Direct URL: 

    https://edupoin.sekolah.id/admin/users
    (Sesuaikan domain dengan sekolah Anda)

    Panduan: Membuat Akun Internal

    Prasyarat

    Untuk GURU: - Guru sudah terdaftar di Personil → Guru - Guru belum punya akun login (field user_id kosong)

    Untuk TENDIK: - Tendik sudah terdaftar di Personil → Tendik - Tendik belum punya akun login (field user_id kosong)

    Langkah 1: Buka Halaman Daftar Akun Internal

    Ikuti petunjuk di bagian Akses Modul Akun Internal

    Langkah 2: Klik Tombol "Buat Akun Internal"

    Di halaman daftar, Anda akan melihat tombol berwarna biru bernama "+ Buat Akun Internal" atau "Buat" di sudut kanan atas.

    Klik tombol tersebut.

    Langkah 3: Isi Form Pembuat Akun Internal

    Anda akan melihat form dengan kolom berikut:

    Nama Lengkap ⭐ WAJIB

    • Deskripsi: Nama user (akan ditimpa otomatis dari actor yang dipilih)
    • Input User: Isikan nama (sementara), akan diganti saat pilih actor
    • Catatan: Field ini otomatis terisi dengan nama dari guru/tendik yang dipilih

    Sumber Akun ⭐ WAJIB

    • Deskripsi: Pilih apakah ini akun Guru atau Tendik
    • Opsi:
    • Guru: Untuk membuat akun guru
    • Tendik: Untuk membuat akun staf/tendik
    • Cara Memilih:
    • Klik dropdown "Pilih salah satu opsi"
    • Pilih "Guru" atau "Tendik"
    • Form akan berubah sesuai pilihan

    Data Guru (muncul jika Sumber = Guru) ⭐ WAJIB

    • Deskripsi: Pilih guru dari daftar
    • Cara Memilih:
    • Klik tombol "Pilih salah satu opsi"
    • Daftar guru yang belum punya akun akan tampil
    • Cari nama guru atau scroll, lalu klik
    • Catatan:
    • Nama Lengkap akan otomatis terisi dengan nama guru
    • Jika guru tidak ada di daftar = semua guru sudah punya akun

    Data Tendik (muncul jika Sumber = Tendik) ⭐ WAJIB

    • Deskripsi: Pilih tendik dari daftar
    • Cara Memilih:
    • Klik tombol "Pilih salah satu opsi"
    • Daftar tendik yang belum punya akun akan tampil
    • Cari nama tendik atau scroll, lalu klik
    • Catatan:
    • Nama Lengkap akan otomatis terisi dengan nama tendik
    • Jika tendik tidak ada di daftar = semua tendik sudah punya akun

    Username ⭐ WAJIB

    • Deskripsi: Username untuk login (harus unik)
    • Rekomendasi GURU:
    • Gunakan NIP — mudah diingat
    • Contoh: 198501012010012004
    • Alternatif: budi.santoso atau guru_budi
    • Rekomendasi TENDIK:
    • Gunakan nama atau singkatan jabatan
    • Contoh: rina.wati atau tu_rina atau admin_sekolah
    • Validasi:
    • Tidak boleh kosong
    • Tidak boleh duplikat dengan user lain
    • Maksimal 100 karakter

    Email (Opsional)

    • Deskripsi: Email guru/tendik (untuk notifikasi, password reset, dll)
    • Format: nama@email.com
    • Catatan: Bisa dikosongkan, bisa ditambah nanti

    Password ⭐ WAJIB

    • Deskripsi: Password awal untuk login
    • Rekomendasi GURU:
    • Gunakan NIP — sesuai dengan username jika pakai NIP
    • Contoh: 198501012010012004
    • Atau password kuat: Guru_Aman2026!
    • Rekomendasi TENDIK:
    • Password kuat custom
    • Contoh: TU_Aman2026! atau Admin@Sekolah2026
    • Validasi:
    • Minimal 8 karakter
    • Tidak boleh kosong
    • Catatan:
    • Password tidak ditampilkan ulang setelah save
    • User dapat ganti password setelah login

    Role ⭐ WAJIB

    • Deskripsi: Role/hak akses untuk user ini
    • Untuk GURU:
    • Role Guru: Default, dapat dipilih
    • Role Wali Kelas: Jika guru adalah wali kelas, pilih ini juga
    • Cara: Klik dropdown, pilih satu atau lebih role
    • Untuk TENDIK:
    • Pilih sesuai jabatan:
      • TU: Untuk Tata Usaha
      • Admin: Untuk admin sistem
      • Kesiswaan: Untuk manajemen siswa/perizinan
      • BK: Untuk bimbingan konseling
      • Guru Piket: Untuk guru piket
      • Atau lainnya sesuai kebutuhan
    • Catatan Penting:
    • ⚠️ Jangan berikan role "Siswa" — gunakan "Akun Siswa" untuk siswa
    • Bisa select multiple role jika user butuh akses lebih dari satu

    Langkah 4: Validasi Input

    Sebelum klik "Buat", pastikan:

    • ✅ Sumber Akun sudah dipilih (Guru / Tendik)
    • ✅ Data Guru/Tendik sudah dipilih
    • ✅ Username terisi (dan belum ada yang sama)
    • ✅ Password terisi (minimal 8 karakter)
    • ✅ Role sudah dipilih (minimal satu)
    • ❌ Kolom berwarna merah = error, harus diisi

    Langkah 5: Klik Tombol "Buat"

    Jika semua kolom valid, klik tombol "Buat" di bagian bawah form.

    Hasil: - ✅ Akun internal berhasil dibuat - ✅ Role ter-assign sesuai pilihan - ✅ Nama Lengkap otomatis dari guru/tendik - ✅ Halaman akan redirect ke detail akun

    Langkah 6: Verifikasi Akun Internal

    Setelah redirect, Anda akan melihat:

    • ✅ Nama user (dari guru/tendik yang dipilih)
    • ✅ Username
    • ✅ Email (jika ada)
    • ✅ Role yang ter-assign
    • ✅ Tanggal pembuatan

    User sekarang dapat login dengan: - Username: [sesuai yang Anda input] - Password: [sesuai yang Anda input]

    Panduan: Mengelola Akun Internal

    Lihat Daftar Akun Internal

    1. Buka menu Sistem & Pengguna → Akun Internal
    2. Anda akan melihat tabel dengan kolom:
    3. Nama: Nama user
    4. Username: Username login
    5. Email: Email (jika ada)
    6. Role: Role/hak akses
    7. Sumber: Asal data (Guru/Tendik)
    8. Aksi: Tombol Edit/Delete
    9. Scroll kanan untuk melihat kolom lain

    Cari Akun Internal

    Di halaman daftar, gunakan kotak "Search / Cari" untuk: - Mencari nama user - Mencari username - Mencari email

    Contoh: ketik budi atau 198501012010012004 atau admin@sekolah.id

    Edit Akun Internal

    Untuk mengubah username, email, password, atau role:

    1. Buka daftar Akun Internal
    2. Cari akun yang ingin diedit
    3. Klik tombol "Edit" (atau nama user)
    4. Anda akan masuk ke halaman edit
    5. Ubah field yang diperlukan:
    6. Nama Lengkap: (read-only, dari data guru/tendik)
    7. Sumber Akun: (read-only, tidak bisa diubah)
    8. Username: Username baru (harus unik)
    9. Email: Email baru (opsional)
    10. Password: Password baru (opsional, biarkan kosong jika tidak ubah)
    11. Role: Tambah/kurang role sesuai kebutuhan
    12. Klik tombol "Simpan" atau "Perbarui"

    Catatan Edit: - Nama dan Sumber Akun tidak bisa diubah (untuk integritas data) - Username tidak bisa kosong - Jika ubah password, user harus login pakai password baru - Email dapat dikosongkan

    Suspend/Disable Akun (Opsional)

    Jika user tidak aktif tapi Anda belum ingin hapus akunnya:

    • Opsi 1: Ubah role ke role minimal (tanpa akses penting)
    • Opsi 2: Ganti password dengan password random, jangan beritahu user
    • Opsi 3: Hubungi IT untuk add suspend feature

    Hapus Akun Internal

    ⚠️ HATI-HATI! Operasi ini tidak dapat dibatalkan.

    Untuk menghapus akun internal:

    1. Buka daftar Akun Internal
    2. Cari akun yang ingin dihapus
    3. Klik tombol "Delete" atau ikon tempat sampah di kolom Aksi
    4. Sistem akan minta konfirmasi: "Apakah Anda yakin?"
    5. Klik "Hapus" untuk confirm

    Hasil Penghapusan: - ❌ Akun user dihapus - ✅ Data biodata guru/tendik tetap ada (untuk audit trail) - ❌ User tidak bisa login lagi - ✅ Riwayat akses, input data tetap tersimpan

    Tips & Best Practice

    🎯 Tips Praktis

    1. Gunakan NIP/NIK untuk Username Guru
    2. NIP sudah unik di tingkat nasional
    3. Mudah diingat guru

    4. Memudahkan rekonsiliasi dengan database pusat

    5. Password Default vs Custom

    6. Guru: Bisa pakai NIP (karena sudah kuat & unik)
    7. Tendik: Gunakan password kuat custom

    8. Jangan pakai pattern yang sama untuk semua

    9. Role Assignment

    10. Guru → Role: "Guru" (+ "Wali Kelas" jika applicable)
    11. TU → Role: "TU"
    12. Admin → Role: "Admin"

    13. Jangan berikan multiple role kecuali benar-benar perlu

    14. Batch Create (untuk sekolah besar)

    15. Jika punya banyak guru/tendik, bisa minta feature bulk import

    16. Lebih efisien daripada satu-satu

    17. Komunikasi ke User

    18. Siapkan kertas berisi username + password
    19. Ajarkan cara login dan ubah password sendiri

    20. Tekankan keamanan password

    21. Reset Password

    22. Guru/tendik bisa reset password sendiri (jika punya email)
    23. Atau admin bisa edit di sini dan set password baru

    ⚠️ Best Practice Keamanan

    • ✅ Password Strength: Minimal 8 karakter, mix huruf/angka/simbol
    • ✅ Jangan Share Password: Setiap user punya password unik
    • ✅ Ganti Password Default: User harus ubah password saat first login
    • ✅ Hindari Pattern: Jangan pakai password yang sama untuk semua
    • ✅ Monitor Login: Alert jika ada login mencurigakan
    • ✅ Backup Data: Backup akun secara berkala
    • ✅ Audit Trail: Tracking setiap perubahan akun

    Pertanyaan Umum (FAQ)

    Q: Apa bedanya "Data Guru" dan "Akun Internal" (jalur Guru)?

    A: - Data Guru = Biodata (nama, NIP, tanggal lahir, status, dll) - Akun Internal (Guru) = Login account (username, password, untuk akses fitur)

    Keduanya terpisah. Anda buat biodata dulu, akun dibuat kemudian.

    Q: Bisa gak membuat akun guru langsung dari menu "Data Guru"?

    A: Tidak. Menu "Data Guru" hanya untuk biodata. Akun dibuat di menu "Akun Internal" yang terpisah.

    Q: Guru mana saja yang bisa dipilih saat buat akun?

    A: Hanya guru yang: - ✅ Sudah terdaftar di Personil → Guru - ✅ Belum punya akun (field user_id kosong)

    Jika guru tidak muncul di dropdown: - ❌ Guru belum terdaftar biodata (buat di Data Guru dulu) - ❌ Guru sudah punya akun (edit akun, jangan buat baru)

    Q: Bagaimana dengan Tendik yang tidak butuh akun (Satpam, Kebersihan)?

    A: Jangan buat akun di menu "Akun Internal" untuk mereka.

    • ✅ Tetap daftarkan biodata di Personil → Tendik
    • ❌ Jangan buat akun login (karena tidak perlu akses sistem)
    • ✅ Data mereka tersimpan untuk keperluan administratif

    Q: Bisa gak ubah Sumber Akun dari Guru jadi Tendik (atau sebaliknya)?

    A: Tidak. Sumber Akun tidak bisa diubah setelah akun dibuat.

    Jika ada kesalahan: 1. Hapus akun yang salah 2. Buat akun baru dengan sumber yang benar

    Q: Apakah nama user otomatis terisi dari guru/tendik?

    A: Ya. Saat Anda pilih guru/tendik, field "Nama Lengkap" akan otomatis terisi dengan nama dari data yang dipilih.

    Ini memastikan nama user selalu sesuai dengan data master.

    Q: Bisa tidak ubah role setelah akun dibuat?

    A: Ya, bisa edit di halaman Edit Akun: 1. Buka daftar Akun Internal 2. Cari akun → Klik Edit 3. Ubah role sesuai kebutuhan 4. Klik Simpan

    Q: Apa yang terjadi jika saya hapus akun guru/tendik?

    A: - ❌ Akun login guru/tendik dihapus — tidak bisa login - ❌ Role dihapus - ✅ Data biodata guru/tendik tetap ada - ✅ Riwayat input data tetap ada (untuk laporan)

    Jadi data administratif aman, hanya akun login yang dihapus.

    Q: Berapa lama username/password berlaku?

    A: Tidak ada batasan waktu. Username dan password berlaku terus sampai: - Admin hapus akun - Admin ubah username/password - User ganti password sendiri

    Q: Jika lupa password guru/tendik, bagaimana?

    A: Admin dapat reset: 1. Buka daftar Akun Internal 2. Cari akun yang lupa password → Klik Edit 3. Isi field Password dengan password baru 4. Klik Simpan 5. User sekarang bisa login dengan password baru

    Alternatif: User klik "Lupa Password" saat login (jika punya email terdaftar).

    Q: Bisakah guru/tendik ganti password sendiri setelah login?

    A: Ya, user bisa: 1. Login ke aplikasi 2. Klik profile/menu pengguna (di atas atau sudut halaman) 3. Pilih "Ubah Password" atau "Settings" 4. Masukkan password lama + password baru

    Q: Apakah buat akun internal bisa di-batch / import dari file?

    A: Untuk versi ini: hanya manual satu per satu.

    Fitur import/bulk create dapat diminta ke tim IT untuk development.

    Q: Apa bedanya "Akun Internal" dan "Akun Siswa"?

    A: - Akun Internal: Untuk guru dan staf sekolah (Personil → Guru/Tendik) - Akun Siswa: Untuk siswa saja (Personil → Siswa)

    Keduanya terpisah untuk keamanan dan kejelasan alur.
